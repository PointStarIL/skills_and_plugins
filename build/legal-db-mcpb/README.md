# legal-db — קובצי מקור לבניית חבילת `.mcpb`

התיקייה הזו **אינה חלק מההפצה**. היא נמצאת מחוץ ל-`plugins/`, ולכן אינה נכנסת לשום פלאג-אין
ואינה מחייבת העלאת גרסה. היא שומרת את מה שנדרש כדי לבנות מחדש את חבילת ה-`.mcpb` של
`legal-db` (תוסף ל-Claude Desktop), ושעד כה היה קיים רק בעותק מקומי על ה-NAS
(`plugins/legal/plugin-src/`).

קוד הפלאג-אין עצמו (`mcp/legal-mcp.ps1`, `hooks/`, `skills/`, `docs/` ועוד) **אינו כאן**.
מקור האמת שלו הוא [`plugins/legal-db/`](../../plugins/legal-db/). נבדק ב-15.11.26 שעשרת
הקבצים המשותפים ב-`plugin-src` זהים לו.

| קובץ | מה זה |
|---|---|
| `manifest.json` | מניפסט ה-mcpb. `__VERSION__` מוחלף בגרסה בזמן הבנייה. `entry_point` מצביע ל-`mcp/legal-mcp.ps1` שבשורש החבילה. |
| `icon.png` | האייקון שהמניפסט מפנה אליו. הוסר בכוונה מהפלאג-אין (קומיט 3c43b08), ונשמר כאן לחבילת ה-mcpb בלבד. |
| `Make-Icon.ps1` | מייצר את `icon.png` (1024×1024, האות ל על ריבוע כחול). |
| `commands-legacy/setup.md` | גרסה ישנה של פקודת ההגדרה, שהוחלפה ב-`commands/legal-setup.md`. לתיעוד בלבד. |

## בנייה (ידנית)

> תהליך הבנייה המקורי לא תועד. הצעדים הבאים משוחזרים ממבנה המניפסט ומתוצרי `dist/`.

1. העתק את תוכן `plugins/legal-db/` לתיקייה זמנית.
2. הוסף אליה את `manifest.json` ואת `icon.png` מכאן, והחלף את `__VERSION__` בגרסה.
3. ארוז עם `mcpb pack` (או zip ושנה סיומת ל-`.mcpb`).

## `dist/` — תוצרי הבנייה של גרסה 1.0.0

תמונת מצב של מה שנבנה והופץ בפועל, כפי שהיה ב-`plugins/legal/dist/` על ה-NAS. נשמר כארכיון.
**לא לערוך כאן.** הקוד שבתוכם זהה ל-`plugins/legal-db` (נבדק ב-15.11.26).

| קובץ | מה זה |
|---|---|
| `legal-db-1.0.0.mcpb` | התוסף ל-Claude Desktop, מוכן להתקנה בלחיצה כפולה. |
| `legal-db-mcpb/` | אותה חבילה, פרוסה. ה-`manifest.json` שבה הוא התבנית עם `version: "1.0.0"`. |
| `legal-db-1.0.0.zip` | הפלאג-אין לבדו, ארוז. |
| `legal-db-marketplace/` + `legal-db-marketplace-1.0.0.zip` | marketplace מקומי עצמאי עם הפלאג-אין. כולל את `icon.png` ואת השדה `icon` ב-`plugin.json`, שהוסרו מאז מ-`plugins/legal-db`. |
