# marcus-law-arnona-committee

חבילת סקילים לניהול תיקי ערר בוועדת ערר לארנונה, מנקודת מבטו של חבר ועדה שכותב החלטות.

## מה יש בחבילה

| סקיל | מה הוא עושה |
|---|---|
| `open-arnona-case` | פותח תיק חדש: מעתיק את תבנית התיק, אוסף את שדות כרטיס התיק בשאלות, פותח יומן גישה ורושם ביומן המרכזי |
| `organize-arnona-folder` | מזהה מסמכים לפי תוכנם, מריץ OCR ומטמיע שכבת טקסט, מתקן עמודים הפוכים, מפצל קבצים מורכבים ונספחים, משנה שמות וממיין לשבע תיקיות התקן |
| `extract-arnona-claims` | מחלץ עובדות וטענות מכתבי בי-דין ומפיק מסמך רקע ותמצית לקראת ההחלטה, עם פרק הערות לכותב |
| `check-arnona-order` | משווה את הסיווג, האזור והשטח שחויבו מול צו הארנונה של שנת החיוב, ומפיק דוח פערים |
| `write-arnona-decision` | מנסח החלטה סופית בכתיבה תמציתית, על שלד אחיד |
| `arnona-interim-decision` | מנסח החלטת ביניים, ומציג את מפת סוגי החלטות הביניים שנמצאו בפרקטיקה |

## תלויות

- **`hebrew-docx-engine`** לבניית כל DOCX עברי. אין להשתמש בסקיל `docx` הגנרי לבניית מסמך עברי מאפס.
- **מבנה תיק בן שבע תיקיות:** `מסמכים מקוריים`, `השגה והחלטת מנהל הארנונה`, `כתבי טענות`, `חומר שומה ומדידות`, `פרוטוקולים ודיונים`, `ניתוח מסמכים`, `החלטות`. בשורש תיקיית התיק יושבים `כרטיס התיק.md` ו-`_יומן גישה.md`.
- **מפת המצביעים של הפרויקט** היא מקור האמת לנתיבים. הסקילים אינם מקודדים נתיבים בתוכם.
- **`check-arnona-order` אינו רץ בלי צו הארנונה** של הרשות לשנת החיוב.

## עקרונות שחוצים את כל הסקילים

1. **איסור המצאה.** ציטוט, פסיקה, חקיקה, סעיף בצו או נתון נכנסים רק אם הם במסמכי התיק או במסד הפסיקה של הפרויקט. פסיקה תומכת מגיעה מהמשתמש.
2. **אין השלמה מהזיכרון.** מה שלא ניתן לאמת, נאמר עליו במפורש.
3. **סיווג לפי תוכן, לא לפי שם קובץ.**
4. **פרקטיקה אינה סמכות.** מה שוועדות אחרות עשו אינו קובע מה מותר.
5. **פרטיות.** אין בסקילים ובקובצי הייחוס אזכור של תיק, של צד, של כתובת או של מספר הליך.
6. **עברית, ללא מקף ארוך.**

## מגבלות שיש להכיר

- **שלד ההחלטה אינו הסגנון האישי של המשתמש.** הוא נגזר מהחלטות של ועדות אחרות. אחרי שייכתבו חמש או שש החלטות משלו, יש להחליף את הבסיס.
- **מפת החלטות הביניים אינה ממצה.** היא נגזרת ממדגם קטן, מרוכז בעיקר בוועדה אחת.
- **נוסח החוק והתקנות אינו בחבילה.** שאלת הסמכות נבדקת מול המקור.
