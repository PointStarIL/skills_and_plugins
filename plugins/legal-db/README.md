# Legal DB – פלאגין לעבודה עם ליגל מתוך Claude

**English summary:** a Claude plugin that lets Claude work with the Legal (ליגל) law-office case-management software through its Access database and document folders: open clients and cases, add calendar events, manage documents and sub-folders, change case status. Every write is previewed first, needs your explicit approval, is backed up automatically and is verified afterwards. Windows only. Unofficial – not made or supported by the Legal vendor.

---

## 1. מה זה ומה זה עושה

הפלאגין מלמד את Claude לעבוד מול מערכת ליגל "כמו שהתוכנה עצמה עושה": הוא כותב ישירות למסד הנתונים של ליגל (`MasTmd.mdb`) ולתיקיית המסמכים שלה, באותם שדות ובאותו סדר שליגל משתמשת בהם, כך שמה שנוצר מופיע בליגל כאילו הוזן בתוכנה.

כשאתה אומר לקלוד "תיצור בליגל…", "תכתוב לליגל…" או "תבדוק בליגל…" הכוונה לעבודה דרך הפלאגין הזה.

**מה אפשר לבקש:**
- **תיקים ולקוחות:** חיפוש לקוח ותיק; פתיחת לקוח חדש ותיק חדש (נזיקין כללי, פלת"ד, ביטוח לאומי, תאונת דרכים עבודה, תיק כללי).
- **תיקיות משנה:** יצירה (גם תיקייה בתוך תיקייה) ושינוי שם.
- **מסמכים:** הוספה, נרמול שם (גם התיאור וגם שם הקובץ), העברה בין תיקיות, מחיקה (הקובץ עובר ל-`DeletedFiles` כמו בליגל).
- **יומן ואירועים:** פגישה, קדם, דיון, תזכורת, משימה, שיחת טלפון, תרשומת, הערכת נזק, ומחיקה שלהם.
- **סטטוס ותיק פתוח/סגור:** שינוי סטטוס, סגירה (סטטוס "סגור" + תאריך סגירה), פתיחה מחדש, יצירת סטטוס חדש (קודם בודקים אם יש דומה).

**מה הפלאגין לא עושה (בכוונה):** חשבוניות, תשלומים והנהלת חשבונות; הוצאה לפועל; עריכת פרטים אישיים של לקוחות; עריכת מודלי תהליך וכללי אוטומציה. בקשות כאלה Claude יסרב להן ויגיד שהן מחוץ לפלאגין.

## 2. דרישות

- Windows 10 / 11, עם ליגל מותקנת באותו מחשב (או שהתיקייה שלה נגישה אליו) והרשאת כתיבה למסד ולתיקיית המסמכים.
- PowerShell של Windows 32 ביט ו-Jet 4.0 (מגיעים עם Windows; ליגל עצמה תלויה בהם).
- Claude Code (או Claude Desktop, לשונית Code) עם תמיכה בפלאגינים.
- הכלים רצים על מחשב ה-Windows של המשרד, ולכן נדרש שהשיחה תהיה מחוברת למחשב דרך אפליקציית Claude לשולחן העבודה (כלי `device_bash`). סיסמת מסד הנתונים של ליגל מובנית בכלים ואינה נשאלת.

## 2א. באילו סביבות הפלאגין עובד

| סביבה | נתמך? | הערה |
|---|---|---|
| **Claude Code** (שורת הפקודה) | כן | |
| **Claude Desktop – לשונית Code** (סביבה מקומית) | **כן** | אותו מנוע של Claude Code, רץ על המחשב שלך ולכן מפעיל את הסקריפטים ופותח את המסד של ליגל. ה-hooks, ה-skill וכרטיסי האישור פועלים. |
| **Cowork** (ושיחה רגילה ב-Claude Desktop) | **חלקית – לפי התיעוד** | אפשר לשייך לשיחה או לפרויקט תיקייה מקומית (למשל תיקיית ליגל) ו-Claude קורא וכותב בה קבצים. אבל פקודות מעטפת וקוד רצים שם במכונה וירטואלית של לינוקס, ולא ב-Windows. כלי הכתיבה של הפלאגין צריך PowerShell של Windows ודרייבר Jet כדי לפתוח את מסד ה-Access, ואלה כנראה אינם זמינים שם (לא מתועד במפורש). לכן ה-skill נטען, אך הכלים כנראה לא ירוצו. |
| **claude.ai** (דפדפן) | לא | אין גישה לקבצים המקומיים. |

הדרך המתועדת לגרום לזה לעבוד גם ב-Cowork היא **שרת MCP מקומי** שרץ על המחשב עצמו (לא במכונה הווירטואלית). **שרת כזה כלול בפלאגין** (`.mcp.json` + `mcp\legal-mcp.ps1`) ומופעל על ידו, והוא חושף רק חמישה כלים מוגבלים (`legal_read`, `legal_preview`, `legal_apply`, `legal_setup_status`, `legal_setup_apply`), בלי מעטפת כללית. לפי התיעוד, שרת MCP של פלאגין נטען ב-Code וב-Cowork כשהשיחה רצה על המחשב, ואינו נטען בשיחה רגילה; לשיחה רגילה ב-Desktop יש גם תוסף עצמאי (`legal-db-<גרסה>.mcpb`) עם אותם כלים. אל תתקין את שניהם לאותה סביבה: ייווצרו שני עותקים של הכלים. ההגדרות, והגיבויים שייכים למשתמש ב-Windows ולכן משותפים בין Code ב-Desktop לשורת הפקודה.
## 3. התקנה

הפלאגין עובד **ב-Claude Code** (שורת הפקודה, או Claude Desktop – לשונית Code), כי הוא מריץ סקריפטים מקומיים על המחשב שבו ליגל.

**א. התקנה מקובץ ה-zip (העלאה):** ב-Claude: *Customize ← Plugins ← Add ← Upload plugin* ובחר את `legal-db-<גרסה>.zip` (אפשר גם קובץ `.plugin`). הקובץ בנוי כך ש-`.claude-plugin\plugin.json` נמצא בשורש הארכיון, כפי שנדרש. ב-**Claude Desktop – לשונית Code**: לחץ על ‎+‎ ליד תיבת ההקלדה ← *Add plugins*, או *Plugins ← Manage plugins*. (נתיבי ה-UI לפי התיעוד; לא נבדקו אצלנו.)

**ב. בדיקה בלי התקנה:** פתח טרמינל והרץ
```
claude --plugin-dir "C:\Tools\legal-db"
```
(או `--plugin-dir` עם קובץ ה-zip). אחרי שינוי: `/reload-plugins`.

**ג. התקנה מחנות מקומית:** פרוק את תיקיית החנות `legal-db-marketplace` למקום קבוע ואז:
```
claude plugin marketplace add C:\Tools\legal-db-marketplace
claude plugin install legal-db@legal-db-marketplace
```
(בתוך שיחה: `/plugin marketplace add …` ו-`/plugin install …`).

לאחר ההתקנה פתח שיחה חדשה. בתחילתה Claude מקבל הודעה `[Legal plugin] root: …` עם מיקום הפלאגין ויגיד לך אם ההגדרה הראשונה הושלמה. לבדיקת תקינות החבילה: `claude plugin validate "<תיקיית הפלאגין>"`.
## 4. הגדרה ראשונה (חובה, פעם אחת)

עד שההגדרה הושלמה הכלי מסרב לעבוד (`[SETUP REQUIRED]`). **בשימוש הראשון ההגדרה מתחילה מעצמה, בתוך השיחה ב-Claude Desktop:** Claude אומר שזו הפעם הראשונה, שואל אותך את שאלות ההגדרה בשאלות עם כפתורים (לכל שאלה ברירת מחדל מסומנת "מומלץ"), ומריץ את האשף עם התשובות שלך. אחר כך הוא ממשיך בבקשה המקורית שלך. אפשר להפעיל את התהליך גם ידנית בכל זמן עם `/legal-db:legal-setup`, או להריץ את האשף בעצמך בטרמינל והוא ישאל את השאלות בעצמו:

```
powershell -NoProfile -File "<תיקיית הפלאגין>\tools\Setup-MasTmd.ps1"
```

האשף שואל שאלה אחר שאלה; כל שאלה מציגה ברירת מחדל ו-Enter מקבל אותה:

| שאלה | הסבר |
|---|---|
| **מצב עבודה** | **אמת** (ברירת מחדל, מומלץ לכל לקוח): עבודה על נתונים אמיתיים בלבד. **בדיקות**: מאפשר נתוני דמה וקיצורי דרך, רק על מחשב בדיקות; דורש להקליד TEST לאישור. |
| **נתיב ליגל** | ברירת מחדל `C:\Timin`. התיקייה שמכילה את `MasTmd.mdb` ואת תיקיית המסמכים `tmpDocs`. אפשר להזין נתיב אחר; האשף בודק שהמסד והתיקייה קיימים שם. |
| **שם משתמש** | שם משתמש ליגל; נכתב כיוצר/שולח של הפריטים. |
| **מע"מ** | באחוזים (ברירת מחדל 18). |
| **מיקום ברירת מחדל לאירועי יומן** | מספר מרשימת המיקומים בליגל, או ריק לבלי מיקום. |
| **גיבויים** | כמה גיבויים לשמור (ברירת מחדל 15) ובאיזו תיקייה. |

ההגדרות נשמרות ב-`%APPDATA%\MasTmd\config.json` (למשתמש הווינדוס הנוכחי, מחוץ לתיקיית הפלאגין). **לשינוי הגדרה בכל זמן:** הרץ את אותו אשף שוב – הוא יציג את ההגדרות הנוכחיות וייתן לשנות כל אחת (נתיב, מצב ועוד).

## 5. עבודה יומיומית

אתה מבקש בשפה רגילה, למשל:
- "פתח תיק נזיקין ללקוח יעקב כהן, טלפון 050-1234567"
- "תוסיף דיון ב-1.2.2027 בשעה 10:00 בתיק 183"
- "תנרמל את שמות המסמכים בתיק של דנה – בלי המילה 'סרוק'"
- "תעביר את כתב התביעה לתיקיית משנה 'כתבי טענות'"
- "תסגור את התיק" / "תשנה את הסטטוס ל'ממתין לתשובת חברת ביטוח'"

בכל פעולה Claude עובד בשלבים: (1) שואל שאלות עם כפתורים ותיבות סימון, (2) מציג **תצוגה מקדימה** של מה ייכתב (בלי לכתוב כלום), (3) מבקש **אישור מפורש**, (4) מבצע, (5) **מאמת** שהמסד והקבצים תואמים ומדווח מה לבדוק בליגל.

## 6. מצב אמת ומצב בדיקות

- **מצב אמת** (ברירת המחדל): הכלי מסרב לנתוני דמה ולקיצורי דרך של בדיקות, ו-Claude לא יצור לקוחות או תיקי "בדיקה". בראש כל הרצה מודפס `[MODE] PRODUCTION`.
- **מצב בדיקות** נועד למחשב בדיקות נפרד בלבד.
- **רק אתה מחליף מצב** (באשף ההגדרה). הפלאגין חוסם קריאות של Claude שנוגעות בקובץ ההגדרות, במשתנה `MASTMD_CONFIG` או באשף, ו-Claude מונחה לא לעקוף זאת.

## 7. בטיחות ואחריות

- **גיבוי אוטומטי** של כל המסד לפני כל כתיבה (בתיקיית `backups` של הכלי), עם שמירה של מספר הגיבויים שהגדרת. הגיבויים כוללים את כל נתוני הלקוחות – שמור אותם בדיסק מוגן.
- **תצוגה מקדימה ואישור** לפני כל כתיבה; כל כתיבה נעשית בטרנזקציה, ובשגיאה השינוי מבוטל (גם קבצים שהועתקו).
- **יומן** של כל כתיבה (`write-log.jsonl`) ו**אימות** אחריה.
- **כלל מקביליות:** אם כרטיס תיק פתוח בליגל בזמן שהכלי כותב לאותו תיק, השמירה הבאה בכרטיס תיכשל ("Row cannot be located for updating"). סגור ופתח את הכרטיס, או אל תערוך אותו תיק בשני המקומות בו-זמנית.
- **הצהרה:** הפלאגין **לא רשמי** ואינו מפותח, מאושר או נתמך על ידי חברת ליגל. הוא כותב ישירות למסד הנתונים; השתמש בו בכפוף למדיניות התמיכה והרישיון של ליגל, ובדוק על עותק לפני עבודה על נתוני אמת. האחריות על השימוש ועל הגיבויים היא על המשתמש.

## 8. פתרון בעיות

| תסמין | פתרון |
|---|---|
| `[SETUP REQUIRED]` | ההגדרה הראשונה לא הושלמה: הרץ את האשף (סעיף 4). |
| "Could not open the database" באשף | הנתיב לתיקיית ליגל שגוי, או שהמסד שייך לגרסה עם סיסמה אחרת. בדוק את הנתיב. |
| "Database 'MasTmd.mdb' not found" | נתיב ליגל שגוי. הרץ את האשף ושנה את הנתיב, או `ShowPaths` להצגת הנתיבים. |
| "Row cannot be located for updating" בליגל | כרטיס תיק פתוח שהשתנה מבחוץ: סגור ופתח אותו. |
| שגיאת 32 ביט / Jet | ודא ש-`C:\Windows\SysWOW64\WindowsPowerShell` קיים ושליגל עצמה נפתחת במחשב. |
| הפלאגין לא מופיע | הפעל מחדש את Claude Code / `/reload-plugins`, ובדוק שהחנות המקומית נוספה. |
| המסד נעול / תפוס | בדוק שאין תהליך אחר שמחזיק אותו בלעדית; נסה שוב. |

## 9. אבטחה ופרטיות

- סיסמת המסד של ליגל זהה בכל ההתקנות ומובנית בכלים; Claude אינו מדפיס אותה.
- כל הנתונים נשארים במחשב: הפלאגין לא שולח מידע לשום שירות חיצוני. Claude עצמו רואה את מה שמודפס בשיחה (למשל שמות לקוחות שהוצגו בתצוגה מקדימה) – פעל בהתאם למדיניות הפרטיות שלך.
- קבצי הגיבוי והיומן מכילים מידע על לקוחות.

## 10. עדכון והסרה

- **עדכון גרסה:** פרוק את החבילה החדשה, הרץ `/plugin update` או התקן מחדש. קובץ ההגדרות (ב-`%APPDATA%`) נשמר.
- **הסרה:** `/plugin uninstall legal-db`. כדי להסיר גם את ההגדרות מחק את `%APPDATA%\MasTmd`; הגיבויים והיומן נמצאים בתיקיית הכלי.

## 11. תוכן החבילה

```
legal-db/
  .claude-plugin/plugin.json
  skills/legal-db/        הנחיות העבודה של Claude + תבניות כרטיסי האישור
  commands/legal-setup.md /legal-db:legal-setup – אשף ההגדרות של ליגל
  hooks/                  הודעת פתיחה (האם ההגדרה הושלמה) + חסימת נגיעה בהגדרות
  tools/                  הכלים (PowerShell) ואשף ההגדרה
  .mcp.json, mcp/         שרת ה-MCP המוגבל שהפלאגין מפעיל (חמישה כלים)
  docs/reference.md       תיעוד כללי על מבנה הנתונים של ליגל
```
