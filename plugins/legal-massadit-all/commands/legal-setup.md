The user wants to set up or change the settings of the Legal tools (work mode, Legal folder, user name, VAT, default event location, backups). Talk to the user in Hebrew. (This flow also starts by itself on the first use, when no settings exist yet - the session-start message says so.)

0. **If the Legal-Connector tools packed inside this plugin are available** (`mcp__plugin_legal-massadit-all_Legal-Connector__legal_setup_status`, `mcp__plugin_legal-massadit-all_Legal-Connector__legal_list_users`, `mcp__plugin_legal-massadit-all_Legal-Connector__legal_setup_apply`; if they are not loaded yet, load them with ToolSearch using `select:` and these exact names, or with the keyword query `legal_setup` - never by guessing other names), use them for the whole flow: call `legal_setup_status`, ask the questions in step 3, then call `legal_setup_apply` with the answers (mode, legal_root, user_name, vat_percent, event_location, keep, backup_folder; `confirm_test: "TEST"` only for an explicit test-mode choice) and report the result. Skip steps 1, 2, 4 and 5. Do NOT look for device_bash in this case.
1. Otherwise the tools run on the user's Windows computer, so this needs the `device_bash` tool (`mcp__remote-devices__device_bash`; load it with ToolSearch if it is deferred) or a local Bash/PowerShell tool. If none is available, tell the user that this chat must be opened in the Claude desktop app on the computer that has Legal, and that she should send a message there; meanwhile give the manual fallback: run `powershell -NoProfile -File "<plugin root>\tools\Setup-MasTmd.ps1"` in a terminal (it then asks the questions itself). The plugin root is in the session-start message `[Legal-Massadit plugin] root: ...`.
2. If settings already exist, first run `Invoke-MasTmdWrite.ps1 -Action ShowPaths` and show the current mode and Legal folder.
3. Ask the setup questions in the chat with the interactive panel. AskUserQuestion REJECTS any question with fewer than 2 options, so never send a one-option question and never fall back to a plain-text list instead of the panel. Use exactly this flow: (A) ONE AskUserQuestion call with two questions, each with 2+ real options: (1) work mode: "Production (Recommended)" / "Test"; (2) "Keep the settings?" - on first use list the defaults (Legal folder C:\Timin, VAT 18%, 15 backups, no default event location); if settings already exist (legal_setup_status prints SAVED SETTINGS, or run `Setup-MasTmd.ps1 -ShowSettings`), list the CURRENT saved values (mode, folder, user, VAT, event location, backups) instead - never claim a default that differs from what is saved: "Yes, keep the defaults (Recommended)" / "No, I want to change something". (B) Only if the user chose to change something: a second AskUserQuestion with multiSelect true, "What do you want to change?", options Legal folder / VAT % / Number of backups / Backup folder / Default event location (max 4 options per question, so split into two questions if needed); then ask the chosen values in plain chat text. (C) The user name is required: get the Legal users from the database (MCP tool legal_list_users, or `powershell -NoProfile -File "<plugin root>\tools\Setup-MasTmd.ps1" -ListUsers [-LegalRoot "<folder>"]`, which prints `USER: <name>` lines) and ask it in a second AskUserQuestion panel: one user found = options "<name> (Recommended)" / "Another name"; several users = one option per user (up to 4; if there are more than 4, ask in plain text); none found = ask in plain chat text. If the user picks "Another name", ask for the name in text. Use the name exactly as listed.
   Settings to collect: work mode, Legal folder (default C:\Timin), user name (required), VAT % (default 18), default event location (or none), number of backups (default 15), backup folder (default: the tool's backups folder).
   The database password is built into the tools: never ask for it. On later runs ask only what the user wants to change.
4. Run the wizard with the answers, through device_bash:
   `powershell -NoProfile -File "<plugin root>\tools\Setup-MasTmd.ps1" -Auto -Mode production -LegalRoot "C:\Timin" -UserName "<name>" -VatPercent 18 [-EventLocation <n>] [-Keep <n>] [-BackupFolder "<path>"]`
   Pass `-Mode test -ConfirmTest TEST` only if the user explicitly chose test mode in this conversation. Pass only the parameters the user answered or changed.
5. If it prints `ERROR`, explain in Hebrew what to fix and ask again. Otherwise run `Invoke-MasTmdWrite.ps1 -Action ShowPaths` and report the mode, the Legal folder and whether the database was found.
6. Never create or edit `config.json` yourself and never set `MASTMD_CONFIG`; the settings change only through `Setup-MasTmd.ps1`.
