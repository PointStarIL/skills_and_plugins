# Legal-Massadit-All – פלאגין לעבודה עם ליגל מתוך Claude

> **גרסת קובץ אחד (ניסוי) – Legal-Massadit-All 1.0.3.** זו גרסה נפרדת של הפלאגין: חבילת התוסף Legal-Connector.mcpb כלולה בתוכה (לפי התיעוד: mcpServers ב-plugin.json מצביע על קובץ .mcpb), ולכן **מעלים קובץ אחד בלבד**. **אל תתקין אותה יחד עם התוסף או עם הפלאגין הרגיל Legal-Massadit** (ייווצרו כלים כפולים). הכלים נקראים כאן $(mcp__plugin_legal-massadit-all_Legal-Connector__)legal_read, legal_preview, legal_apply, legal_setup_status, legal_list_users, legal_setup_apply; הפקודה היא /legal-massadit-all:legal-setup. לפי התיעוד, שרת MCP של פלאגין נטען בשיחות שרצות על המחשב (לשונית Code עם סביבה Local, ו-Cowork מקומי), ולא בשיחות ענן. אם הוא לא נטען, ב-Claude Code אפשר לבדוק עם /mcp. בכל מקום בהמשך שכתוב "התוסף" או "Legal-Connector" – הכוונה לשרת הפנימי של הפלאגין הזה; סעיפי ההתקנה של ה-.mcpb לא רלוונטיים.


**גרסה 1.0.3** · **English summary:** a Claude plugin (skills + setup wizard) that, together with the **Legal-Connector** Claude Desktop extension (the tools), lets Claude work with the Legal (ליגל) law-office case-management software through its Access database and document folders: open clients and cases, add calendar events, manage documents and sub-folders, change case status. Every write is previewed first, needs your explicit approval, is backed up automatically and is verified afterwards. Windows only. Unofficial – not made or supported by the Legal vendor.

## 1. מה זה ומה זה עושה

המערכת מלמדת את Claude לעבוד מול ליגל "כמו שהתוכנה עצמה עושה": היא כותבת ישירות למסד הנתונים של ליגל (`MasTmd.mdb`) ולתיקיית המסמכים שלה, באותם שדות ובאותו סדר שליגל משתמשת בהם, כך שמה שנוצר מופיע בליגל כאילו הוזן בתוכנה.

כשאתה אומר לקלוד "תיצור בליגל…", "תכתוב לליגל…" או "תבדוק בליגל…" הכוונה לעבודה דרך המערכת הזאת.

**מה אפשר לבקש:**
- **תיקים ולקוחות:** חיפוש לקוח ותיק; פתיחת לקוח חדש ותיק חדש (נזיקין כללי, פלת"ד, ביטוח לאומי, תאונת דרכים עבודה, תיק כללי).
- **תיקיות משנה:** יצירה (גם תיקייה בתוך תיקייה) ושינוי שם.
- **מסמכים:** הוספה, נרמול שם (גם התיאור וגם שם הקובץ), העברה בין תיקיות, מחיקה (הקובץ עובר ל-`DeletedFiles` כמו בליגל).
- **יומן ואירועים:** פגישה, קדם, דיון, תזכורת, משימה, שיחת טלפון, תרשומת, הערכת נזק, ומחיקה שלהם.
- **סטטוס ותיק פתוח/סגור:** שינוי סטטוס, סגירה (סטטוס "סגור" + תאריך סגירה), פתיחה מחדש, יצירת סטטוס חדש (קודם בודקים אם יש דומה).

**מה המערכת לא עושה (בכוונה):** חשבוניות, תשלומים והנהלת חשבונות; הוצאה לפועל; עריכת פרטים אישיים של לקוחות; עריכת מודלי תהליך וכללי אוטומציה. בקשות כאלה Claude יסרב להן ויגיד שהן מחוץ למערכת.

## 4. התקנה (בסדר הזה)

1. **הסר גרסה קודמת:** ב-Claude Desktop, *Settings ← Extensions*, הסר "Legal DB" או "Legal-Connector" ישנים. ב-*Customize ← Plugins* הסר את הפלאגין הישן (`legal-db`). שינוי שם יוצר פריט חדש, ולכן ההסרה מונעת עותקים כפולים של הכלים.
2. **התקן את התוסף:** גרור את `Legal-Connector-<גרסה>.mcpb` לחלון *Settings ← Extensions* (או לחיצה כפולה על הקובץ) ואשר. הוא צריך להופיע כ-**Legal-Connector** עם הסטטוס Running.
3. **התקן את הפלאגין:** *Customize ← Plugins ← Add ← Upload plugin* ובחר את `Legal-Massadit-<גרסה>.zip`. בלשונית Code: ‎+‎ ליד תיבת ההקלדה ← *Add plugins*.
   - בדיקה בלי התקנה: `claude --plugin-dir "<תיקיית הפלאגין>"` ואחרי שינוי `/reload-plugins`.
   - חנות מקומית: פרוק את `legal-massadit-marketplace`, ואז `claude plugin marketplace add <תיקייה>` ו-`claude plugin install legal-massadit@legal-massadit-marketplace`.
4. **סגור את Claude Desktop לגמרי** (גם מהמגש ליד השעון) ופתח מחדש.
5. **פתח שיחה חדשה** שרצה על המחשב (לשונית Code, סביבה Local). בתחילתה תופיע הודעה `[Legal-Massadit plugin] root: …` ואם ההגדרה הושלמה.
6. **ההגדרה הראשונה** (סעיף 5) מתחילה מעצמה, או `/legal-massadit-all:legal-setup`.

לבדיקת תקינות החבילה: `claude plugin validate "<תיקיית הפלאגין>"`.

## 5. הגדרה ראשונה (חובה, פעם אחת)

עד שההגדרה הושלמה הכלי מסרב לעבוד (`[SETUP REQUIRED]`). **בשימוש הראשון ההגדרה מתחילה מעצמה, בתוך השיחה.** Claude אומר שזו הפעם הראשונה ושואל בלוחות בחירה (כפתורים ותיבות סימון):

1. **לוח ראשון (שתי שאלות):** מצב עבודה (אמת – מומלץ / בדיקות), ו"להשאיר את ההגדרות?" – כן (מומלץ) / לא, אני רוצה לשנות משהו. בשימוש ראשון השאלה מציגה את ברירות המחדל (תיקיית `C:\Timin`, מע"מ 18%, 15 גיבויים, בלי מיקום ברירת מחדל לאירועים). **אם כבר נשמרו הגדרות, היא מציגה את הערכים השמורים בפועל** (מצב, תיקייה, משתמש, מע"מ, מיקום אירועים, גיבויים), ואפשר לראות אותם גם עם `Setup-MasTmd.ps1 -ShowSettings`.
2. **אם בחרת לשנות:** לוח עם תיבות סימון מה לשנות (תיקיית ליגל, מע"מ, מספר גיבויים, תיקיית גיבויים, מיקום אירועים), ואז הערכים בכתיבה.
3. **שם משתמש:** Claude קורא את המשתמשים הפעילים **מתוך מסד ליגל** (כלי `legal_list_users`) ומציג אותם לבחירה. משתמש אחד: "שמו (מומלץ)" / "שם אחר". כמה משתמשים: אפשרות לכל אחד (עד ארבעה; מעל זה – בכתיבה). אם לא נמצא אף משתמש, השם נשאל בכתיבה.
4. Claude שומר את התשובות (`legal_setup_apply`) ומראה את ההגדרות. אחר כך הוא ממשיך בבקשה המקורית.

אפשר להפעיל את התהליך בכל זמן עם `/legal-massadit-all:legal-setup` (גם לשינוי הגדרות), או להריץ את האשף בעצמך בטרמינל והוא ישאל בעצמו:

```
powershell -NoProfile -File "<תיקיית הפלאגין>\tools\Setup-MasTmd.ps1"
```

הגדרות שהאשף שומר:

| הגדרה | הסבר |
|---|---|
| **מצב עבודה** | **אמת** (ברירת מחדל, מומלץ לכל לקוח): נתונים אמיתיים בלבד. **בדיקות**: נתוני דמה וקיצורי דרך, רק על מחשב בדיקות; דורש אישור מפורש (`TEST`). |
| **נתיב ליגל** | ברירת מחדל `C:\Timin`: התיקייה שמכילה את `MasTmd.mdb` ואת `tmpDocs`. האשף בודק שהן קיימות. |
| **שם משתמש** | משתמש ליגל; נכתב כיוצר/שולח של הפריטים. |
| **מע"מ** | באחוזים (ברירת מחדל 18). |
| **מיקום ברירת מחדל לאירועי יומן** | מספר מרשימת המיקומים בליגל, או ריק. |
| **גיבויים** | כמה גיבויים לשמור (ברירת מחדל 15) ובאיזו תיקייה. |

ההגדרות נשמרות ב-`%APPDATA%\MasTmd\config.json` (למשתמש ה-Windows הנוכחי, מחוץ לתיקיות התוסף והפלאגין, ולכן שורדות עדכון).

בכל פעולה Claude עובד בשלבים: (1) שואל שאלות עם כפתורים ותיבות סימון, (2) מציג **תצוגה מקדימה** של מה ייכתב (`legal_preview`, בלי לכתוב כלום), (3) מבקש **אישור מפורש**, (4) מבצע (`legal_apply` עם האסימון של התצוגה המקדימה, חד-פעמי ובתוקף 15 דקות), (5) **מאמת** ומדווח מה לבדוק בליגל.

## 7. מצב אמת ומצב בדיקות

- **מצב אמת** (ברירת המחדל): הכלי מסרב לנתוני דמה ולקיצורי דרך של בדיקות, ו-Claude לא יצור לקוחות או תיקי "בדיקה". בראש כל הרצה מודפס `[MODE] PRODUCTION`.
- **מצב בדיקות** נועד למחשב בדיקות נפרד בלבד.
- **רק אתה מחליף מצב** (באשף ההגדרה). כלי התוסף לא מאפשרים לעקוף זאת, והפלאגין חוסם קריאות של Claude שנוגעות בקובץ ההגדרות או במשתנה העקיפה שלו.

## 8. בטיחות ואחריות

- **גיבוי אוטומטי** של כל המסד לפני כל כתיבה (בתיקיית `backups` של הכלי), עם שמירה של מספר הגיבויים שהגדרת. הגיבויים כוללים את כל נתוני הלקוחות – שמור אותם בדיסק מוגן.
- **תצוגה מקדימה ואישור** לפני כל כתיבה; כל כתיבה נעשית בטרנזקציה, ובשגיאה השינוי מבוטל (גם קבצים שהועתקו).
- **יומן** של כל כתיבה (`write-log.jsonl`) ו**אימות** אחריה.
- **כלל מקביליות:** אם כרטיס תיק פתוח בליגל בזמן שהכלי כותב לאותו תיק, השמירה הבאה בכרטיס תיכשל ("Row cannot be located for updating"). סגור ופתח את הכרטיס.
- **הצהרה:** המערכת **לא רשמית** ואינה מפותחת, מאושרת או נתמכת על ידי חברת ליגל. היא כותבת ישירות למסד הנתונים; השתמש בה בכפוף למדיניות התמיכה והרישיון של ליגל, ובדוק על עותק לפני עבודה על נתוני אמת. האחריות על השימוש ועל הגיבויים היא על המשתמש.

## 10. אבטחה ופרטיות

- סיסמת המסד של ליגל זהה בכל ההתקנות ומובנית בכלים; Claude אינו מדפיס אותה.

- קבצי הגיבוי והיומן מכילים מידע על לקוחות.

## 11. עדכון והסרה

- **עדכון:** התקן את התוסף והפלאגין החדשים (אחרי הסרת הישנים אם השם השתנה), הפעל מחדש את Claude Desktop ופתח שיחה חדשה. קובץ ההגדרות נשמר.
- **הסרה:** ב-*Settings ← Extensions* הסר את Legal-Connector; ב-*Customize ← Plugins* הסר את Legal-Massadit (`/plugin uninstall legal-massadit`). כדי להסיר גם את ההגדרות מחק את `%APPDATA%\MasTmd`; הגיבויים והיומן נמצאים בתיקיית הכלי.
