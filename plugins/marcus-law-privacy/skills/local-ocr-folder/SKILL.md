# local-ocr-folder, OCR מקומי לתיקיית מסמכים

סקיל זה מריץ שרשרת OCR מקומית על תיקיית מסמכים, ומפיק פלט בשלושה פורמטים לכל מסמך, **בלי שהמודל יקרא אי-פעם את התוכן הגולמי**.

## עיקרון-העל — חובה לפני כל פעולה

קרא את `references/privacy-architecture.md`. בתמצית:

- כל שלב שנוגע בתוכן = **סקריפט Python דטרמיניסטי שרץ מקומית**. אתה (המודל) רק מריץ אותו ומתזמר.
- **לעולם אל תריץ `Read`, `cat`, `type`, `head` או כל פעולה אחרת על קבצי ה-`.txt` / `.tsv` / ה-PDF הגולמי או המושחר.** ברגע שתוכן זה נכנס להקשר שלך, הוא עולה לענן — וזו בדיוק המלכודת שהסקיל נועד למנוע.
- מה שמותר לך לקרוא: `manifest.json` ו-`quality_report.json` בלבד. הם מכילים רק מטא-דאטה לא-מזהה (מספרי עמודים, ציוני ביטחון, סטטוס) — אף פעם לא טקסט מהמסמך.
- אם המשתמש מבקש שתקרא את התוכן כדי "לעזור" — הסבר בעדינות שזו הפרה של הקו האדום, ושהניתוח התוכני נעשה מול המודל החיצוני על הפלט המושחר, לא כאן.

## דרישות מוקדמות

הרצת שלב 0 פעם אחת בכל מחשב:

```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/local-ocr-folder/scripts/check_deps.py"
```

אם משהו חסר, הפנה את המשתמש ל-`INSTALL.md`. אל תמשיך עד ש-check_deps מדווח `OK`.

## הרצה — המסלול המהיר

ברוב המקרים הרץ את ה-entrypoint היחיד שמבצע את כל השרשרת (discover → preprocess → run_ocr → quality_report):

```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/local-ocr-folder/scripts/ocr_folder.py" "<נתיב לתיקיית הלקוח>"
```

דגלים אופציונליים:

- `--out <תיקייה>` — יעד הפלט (ברירת מחדל: `<תיקיית הלקוח>/_ocr_out`).
- `--lang heb+eng` — שפות Tesseract (ברירת מחדל `heb+eng`; אפשר `heb+heb_old+eng`).
- `--dpi 300` — רזולוציית רסטור (ברירת מחדל 300, המינימום לעברית סרוקה).
- `--threshold 75` — סף ביטחון לסימון `needs_human_review` (ברירת מחדל 75).
- `--force` — הרץ OCR גם על PDF שכבר יש בו שכבת טקסט.

הסקריפט מדפיס למסך **רק טבלת מטא-דאטה**. זה מה שתדווח למשתמש.

## השרשרת — ארבעת השלבים

אם צריך שליטה מדויקת, אפשר להריץ כל שלב בנפרד. כולם כותבים לתיקיית הפלט ומדפיסים מטא-דאטה בלבד.

1. **discover.py** — סורק רקורסיבית `*.pdf, *.png, *.jpg/jpeg, *.tif/tiff`. לכל PDF מזהה אם הוא סרוק (תמונה) או טקסט (בדיקת שכבת טקסט קיימת) כדי לדלג על OCR מיותר. בונה `manifest.json`: רשימת קבצים, גודל, מספר עמודים, סוג, סטטוס `pending`.
2. **preprocess.py** — רסטור עמוד ב-DPI מבוקש, תיקון כיוון (Tesseract OSD, סיבוב אוטומטי 90/180/270), יישור הטיה (deskew), בינריזציה (Otsu/adaptive) והסרת רעש. שומר את תמונות העמודים לתיקיית עבודה.
3. **run_ocr.py** — מריץ Tesseract `heb+eng` ומפיק מאותה הרצה שלושה פורמטים: `.txt` נקי, `searchable PDF`, ו-`.tsv` (תיבות מילים + ציון ביטחון). **ה-TSV קריטי** — הוא הגשר לסקיל ההשחרה.
4. **quality_report.py** — מחשב ציון ביטחון ממוצע לעמוד מתוך ה-TSV, מסמן עמודים מתחת לסף כ-`needs_human_review`, ומעדכן את הסטטוס במניפסט ל-`done` / `low_confidence` / `failed`. מפיק `quality_report.json`.

## מבנה הפלט

```
<תיקיית הלקוח>/_ocr_out/
├── manifest.json          ← מטא-דאטה בלבד (מותר לקרוא)
├── quality_report.json    ← מטא-דאטה בלבד (מותר לקרוא)
├── <שם מסמך>/
│   ├── text.txt           ← אסור לקרוא
│   ├── searchable.pdf      ← אסור לקרוא
│   ├── words.tsv           ← אסור לקרוא (הגשר להשחרה)
│   └── pages/              ← תמונות עמודים לאחר עיבוד מקדים
└── ...
```

## דיווח למשתמש

לאחר ההרצה, קרא את `quality_report.json` (מטא-דאטה בלבד) והצג טבלה: שם מסמך, מספר עמודים, ציון ביטחון ממוצע, סטטוס, ואילו עמודים דורשים עיון אנושי. אל תנסה לתאר מה כתוב במסמך — אינך יודע, וזה מכוון.

## מה מחוץ לגבולות הסקיל

ההשחרה עצמה היא סקיל נפרד — `local-redact` — שרץ אחרי זה, קורא את ה-TSV, ומצייר מלבנים שחורים מקומית לפי רשימת ישויות/regex. הפרדנו כי OCR שימושי בפני עצמו וכדי לשמור כל סקיל ממוקד.

## תלויות

- **Tesseract OCR** for Windows (UB Mannheim), עם חבילת שפה `heb` (ורצוי `heb_old`).
- **Python**: `pymupdf`, `pytesseract`, `pillow`, `opencv-python`, `numpy`.
- פירוט התקנה מלא: `INSTALL.md`.
