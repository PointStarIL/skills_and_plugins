## איסור מוחלט: מקף ארוך (Em Dash)

**אסור בתכלית האיסור להשתמש בתו המקף הארוך `—` (em dash, U+2014) בשום מסמך שנוצר בסקיל זה.**

המקף הארוך הוא סימן מובהק לתוכן שנוצר ע"י AI ויש להימנע ממנו לחלוטין. הכלל חל על:

- כל מחרוזת טקסט (`TextRun`) בקוד JavaScript של docx-js
- כל תוכן XML שנכנס ל-`word/document.xml` בעריכת DOCX קיים
- כל פסקה, כותרת, ציטוט, תא בטבלה, הערת שוליים, header/footer, או comment
- כל פלט ביניים (markdown, JSON, scripts) שמשמש לבניית המסמך

### חלופות מותרות

| במקום | השתמש ב... | דוגמה |
|-------|-----------|-------|
| `—` (em dash, U+2014) | `-` (hyphen-minus, U+002D) | "סעיף 19(ב)(4) - תנאים מצטברים" |
| `—` להפרדת סעיף | `:` או `,` או `.` | "המלצה: דחייה" / "המלצה, לאור הניתוח" |
| `—` לרשימה | `:` ואז פסקה חדשה | "הנימוקים:\n1. ..." |
| `, ` (en dash, U+2013) - גם הוא נמנע | `-` (hyphen-minus) | טווחים: "2020-2024" |

### בדיקה אוטומטית לפני שמירה

לפני כל קריאה ל-`Packer.toBuffer(doc)` או ל-`pack.py`, **חובה** להריץ בדיקה שמוודאת שאין em dash בקוד או בפלט:

```bash
# בדיקה בקובץ ה-script (לפני הרצה)
grep -nP '[\x{2014}\x{2013}]' build-doc.js && echo "נמצא מקף ארוך - תקן לפני הרצה" || echo "נקי"

# בדיקה בקובץ ה-DOCX (אחרי בנייה)
unzip -p output.docx word/document.xml | grep -cP '[\x{2014}\x{2013}]' || echo "אין מקף ארוך במסמך"
```

אם הבדיקה מוצאת מקף ארוך - **עצור, החלף ב-hyphen רגיל (`-`), והרץ שוב.**

### החלפה אוטומטית של תוכן מקור

אם המקור (markdown של המשתמש, מסמך מצורף, טיוטה מ-law-mate) מכיל `—` או `, ` - **חובה להחליף אוטומטית ל-`-` בעת בניית ה-DOCX, אל תעתיק כמו שהוא.** הוסף בראש כל script:

```javascript
const sanitizeDashes = (s) => String(s).replace(/[, , ]/g, '-');

// לעטוף כל מחרוזת לפני TextRun:
const run = (text, opts = {}) => new TextRun({
  text: sanitizeDashes(text),
  // ... שאר ההגדרות
});
```

### למה זה חשוב?

1. **אינדיקטור AI:** מקף ארוך הוא מהסימנים הבולטים ביותר לטקסט שנוצר ע"י LLM.
2. **אסתטיקה משפטית:** מסמכים משפטיים ישראליים מסורתיים משתמשים ב-hyphen רגיל או בנקודה/פסיק.
3. **קריאות RTL:** ה-em dash נראה לעיתים שבור או לא מיושר נכון בטקסט עברי.

> **כלל ברזל:** הכלל הזה גובר על כל דוגמת קוד אחרת בסקיל. אם נתקלת בדוגמה בסקיל הזה שמכילה `—` - התעלם מהמקף, השתמש ב-`-` במקומו.

## קריטי: כללי RTL שחייבים לזכור

### הכלל המרכזי: START/END במקום LEFT/RIGHT

**במסמך עברי עם `bidirectional: true`, לעולם אל תשתמש ב-`AlignmentType.LEFT` או `AlignmentType.RIGHT` לפסקאות ומספור!**

| רוצה יישור ל... | לא להשתמש | להשתמש |
|-----------------|-------------|----------|
| **ימין** | `LEFT` או `RIGHT` | `AlignmentType.START` |
| **שמאל** | `LEFT` או `RIGHT` | `AlignmentType.END` |
| **מרכז** | - | `AlignmentType.CENTER` |
| **שני צדדים** | - | `AlignmentType.BOTH` |

> **למה?** כש-`bidirectional: true`, Word מתבלבל עם LEFT/RIGHT. `START` = התחלה = ימין ב-RTL, `END` = סוף = שמאל ב-RTL.

### שלוש הגדרות RTL חובה

כל מסמך עברי חייב את **שלושת** ההגדרות הבאות בכל הרמות:

```javascript
// 1. ברמת ה-Section
sections: [{
  properties: {
    bidi: true  // ← חובה!
  }
}]

// 2. ברמת כל Paragraph
new Paragraph({
  bidirectional: true,  // ← חובה!
  alignment: AlignmentType.BOTH,  // או START/CENTER/END
})

// 3. ברמת כל TextRun
new TextRun({
  text: "טקסט בעברית",
  rightToLeft: true,  // ← חובה!
  font: "David",
})
```

**חוסר באחת מהן = יישור שגוי או טקסט הפוך!**

## זיהוי סוג מסמך - Document Type Detection

**לפני יצירת מסמך, זהה את סוגו.** לכל סוג יש מבנה שונה:

| סוג מסמך | דוגמאות | Header בית משפט? | מבנה מיוחד |
|----------|---------|------------------|------------|
| **כתב טענות** | תביעה, הגנה, בקשה, ערעור, תצהיר, בר"ע | כן | טבלת Header עם בית משפט + מספר תיק |
| **מכתב התראה** | התראה, דרישה, מכתב עו"ד | לא | לוגו/פרטי משרד, "הנדון:", חתימה |
| **הסכם/חוזה** | הסכם שירותים, NDA, חוזה שכירות | לא | הואילים, צדדים, חתימות בשני טורים |
| **מסמך כללי** | חוות דעת, מזכר, סיכום | לא | לפי הצורך |

### טריגרים לזיהוי

```
כתב טענות ← "בית משפט", "בית הדין", "תביעה", "הגנה", "בקשה", 
             "ערעור", "תצהיר", "המבקש", "המשיב", "התובע", "הנתבע", "בר\"ע"

מכתב התראה ← "התראה", "דרישה", "לכבוד", "הנדון:", "נשלח מבלי לפגוע"

הסכם/חוזה ← "הסכם", "חוזה", "בין:", "לבין:", "הואיל", "צד א'", "צד ב'",
             "ולראיה באו הצדדים"
```

## מספור סעיפים משפטיים

**שים לב: `alignment: AlignmentType.START` - לא LEFT ולא RIGHT!**

```javascript
numbering: {
  config: [{
    reference: "legal-clauses",
    levels: [
      {
        level: 0,
        format: LevelFormat.DECIMAL,
        text: "%1.",
        alignment: AlignmentType.START,  // START, לא RIGHT!
        suffix: "tab",
        style: { paragraph: { indent: { left: 720, hanging: 360 } } }
      },
      {
        level: 1,
        format: LevelFormat.DECIMAL,
        text: "%1.%2",
        alignment: AlignmentType.START,  // START, לא RIGHT!
        suffix: "tab",
        style: { paragraph: { indent: { left: 1440, hanging: 500 } } }
      },
      {
        level: 2,
        format: LevelFormat.DECIMAL,
        text: "%1.%2.%3",
        alignment: AlignmentType.START,  // START
        suffix: "tab",
        style: { paragraph: { indent: { left: 2160, hanging: 640 } } }
      }
    ]
  }]
}
```

**שימוש:**
```javascript
new Paragraph({
  bidirectional: true,
  numbering: { reference: "legal-clauses", level: 0 },
  children: [new TextRun({ text: "תוכן הסעיף", font: "David", size: 24, rightToLeft: true })]
})
```

> **הבעיה שנפתרה:** בלי `AlignmentType.START`, המספור מופיע כ-".1" במקום "1."

## אמינות תוכן משפטי - כלל הברזל

### העיקרון

כל מסמך משפטי שנוצר באמצעות סקיל זה - תוכנו חייב להיות מבוסס אך ורק על מידע שסופק במפורש: מסמכים מצורפים, הנחיות המשתמש, או ידע משפטי כללי ומבוסס.

### כללים

1. **לעולם אל תמציא:**
   - פסקי דין, מספרי תיקים, או ציטוטים
   - עובדות שלא סופקו במסמכי המקור
   - סכומים, תאריכים, או נתונים שלא ניתנו

2. **כשחסר מידע - סמן במפורש:**
   - השתמש ב-`[להשלמה: תאריך ההסכם]` או `[להשלמה: סכום]`
   - אל "תמלא את החורים" בניחוש

3. **עדיף מסמך חלקי ומדויק מאשר מסמך מלא עם שגיאות.** אם חסר מידע קריטי, כתוב את המסמך עם סימוני [להשלמה] ופרט בסוף מה עוד צריך לקבל מהמשתמש.

4. **הפרד בין ידוע לא-ידוע.** אם יש לך ידע משפטי כללי (למשל: המסגרת הנורמטיבית של חוק התכנון והבנייה) - אפשר לכתוב על בסיסו. אם יש פרט ספציפי שאתה לא בטוח לגביו - סמן.
