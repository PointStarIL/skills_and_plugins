# marcus-law-drafting

חבילת ניסוח וייצור מסמכים משפטיים: בניית מסמכי DOCX בעברית RTL, ניקוי טיוטות law-mate, עריכה מתקדמת, וכריכת נספחים ל-PDF. כוללת 4 סקיילים.

## סקיילים בחבילה

- hebrew-docx-engine — מנוע העיצוב, מקור-אמת יחיד ל-DOCX עברי (RTL, פונט David, מספור, סגנונות)
- edit-legal-docx — מבנה מסמכים משפטיים ועריכה מתקדמת של DOCX קיים (tracked changes, comments)
- clean-lawmate-draft — עיבוד וניקוי טיוטות law-mate למסמך מלוטש
- build-appendix-pdf — כריכת נספחים ל-PDF מוכן להגשה לבית המשפט
