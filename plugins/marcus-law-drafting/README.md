# marcus-law-drafting

חבילת ניסוח וייצור מסמכים משפטיים: בניית מסמכי DOCX בעברית RTL, עריכה מתקדמת, וכריכת נספחים ל-PDF. כוללת 3 סקיילים.

## סקיילים בחבילה

- hebrew-docx-engine — **מנוע ה-DOCX היחיד** ומקור-האמת לעיצוב (RTL, פונט David, מספור בארבע רמות, סגנונות). כל בנייה של מסמך Word עברי מאפס, בכל החבילות, עוברת דרכו.
- edit-legal-docx — מבנה מסמכים משפטיים ועריכה מתקדמת של DOCX קיים (tracked changes, comments)
- build-appendix-pdf — כריכת נספחים ל-PDF מוכן להגשה לבית המשפט
