# marcus-law-client-management

חבילת ניהול לקוחות: ניתוח, מיון וסיכום מסמכי לקוח מהסיוע המשפטי, והכנת הצעת מחיר
והסכם שכר טרחה בתיקי ביטוח לאומי לפי התקרה שהחוק מתיר. כוללת שני סקיילים.

## סקיילים בחבילה

- organize-client-folder — ניתוח, מיון וסיכום מסמכי לקוח מהסיוע המשפטי
- btl-fee-quote — הצעת מחיר והסכם שכר טרחה בתיק ביטוח לאומי, כפוף לתקרה

## btl-fee-quote, נתיבי מקור

הסקיל נשען על שני קבצים בתיקיית הפרויקט `ניהול תיקים - ביטוח לאומי`:

| קובץ | תפקיד |
|---|---|
| `_מערכת\שכר טרחה\שכר טרחה מקסימלי - ביטוח לאומי.md` | מקור האמת, העתק מאומת של עמודי המוסד |
| `_מערכת\שכר טרחה\btl_fee_cap.py` | מחשבון התקרה |

**התעריפים משתנים מעת לעת.** הסקיל מאמת אותם מול אתר המוסד לפני כל הצעת מחיר,
ומעדכן את שני הקבצים כשמשהו השתנה.
