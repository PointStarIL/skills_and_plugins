מקור אמת לכתובות של פרויקט מסוים.

## קריאות ה-API

כל הקריאות הן JSON. אימות המנהל נעשה בטוקן שמתקבל בכניסה ותקף שתים עשרה שעות.

```bash
BASE=https://api-v2.appdeploy.ai/app/app-fhhd3x

# כניסת מנהל
TOK=$(curl -s -X POST "$BASE/api/admin/login" \
  -H 'content-type: application/json' \
  -d '{"password":"<סיסמת המנהל מקובץ הפרויקט>"}' \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['adminToken'])")
```

## יצירת שאלון חדש

```bash
curl -s -X POST "$BASE/api/admin/forms" \
  -H 'content-type: application/json' \
  -d @create.json
```

`create.json`:

```json
{
  "adminToken": "<TOK>",
  "label": "שם הלקוח",
  "caseNumber": "88",
  "lang": "he",
  "schema": [ ... מערך הפרקים ... ],
  "schemaVersion": "2026-08-26",
  "sourceDocs": [
    "סיכום וניתוח תיק - 26.8.26",
    "שאילתות ל-LawMate - 26.8.26",
    "מחקר LawMate - 27.8.26"
  ]
}
```

- `lang` הוא שפת ברירת המחדל שבה השאלון נפתח. ללקוח שאינו דובר עברית, `en`. בכל
  מקרה יש מתג החלפה בראש העמוד.
- `sourceDocs` הוא תיעוד: אילו שלושה מסמכים הזינו את השאלון. רשום את שמותיהם
  כפי שהם בתיק, כדי שיהיה אפשר לדעת בדיעבד על מה השאלון נשען.

**התשובה מחזירה את הסיסמה פעם אחת בלבד:**

```json
{ "id": "<מזהה השאלון>", "password": "ABCD-EFGH-JKLM", "form": { ... } }
```

**שמור אותה מיד.** אין דרך לשחזר אותה. שאלון שאבדה סיסמתו נמחק ונוצר מחדש.

## עדכון שאלון קיים

לשינוי השאלות בשאלון שטרם נשלח:

```bash
curl -s -X PUT "$BASE/api/admin/forms/<מזהה>" \
  -H 'content-type: application/json' \
  -d '{"adminToken":"<TOK>","schema":[...],"schemaVersion":"..."}'
```

העדכון **אינו** משנה את הקישור ואינו משנה את הסיסמה, ואינו מוחק תשובות שכבר נשמרו.
תשובה לשאלה שהוסרה מהשאלון נשארת בנתונים אך אינה מוצגת.

## הורדת התשובות

```bash
curl -s "$BASE/api/admin/forms/<מזהה>?adminToken=$TOK"
```

מחזיר את מצב השאלון, את מפת התשובות `answers`, ואת `snapshot`, שהוא מערך מפורט של
כל שאלה עם נוסחה בשתי השפות ועם התשובה. **`snapshot` הוא מה שמתייקים**, מפני שהוא
מובן גם בלי הסכמה.

אפשר גם להוריד ידנית: במסך הניהול, כפתור "הורד JSON" בשורת הלקוח.

## מחיקת שאלון

```bash
curl -s -X DELETE "$BASE/api/admin/forms/<מזהה>?adminToken=$TOK"
```

**מחק מיד לאחר שהתשובות ירדו ותויקו.** המחיקה סופית ואין ממנה שחזור.

## כשמשהו נכשל

| מה קרה | מה לעשות |
|---|---|
| `401 unauthorized` בקריאת מנהל | הטוקן פג. היכנס שוב |
| `409 already initialized` | המערכת כבר אותחלה. זה תקין, אין לאתחל שוב |
| `404 not found` בקישור הלקוח | השאלון נמחק, או שהמזהה שגוי |
| הלקוח מדווח שהסיסמה אינה עובדת | ודא שאין רווח בהעתקה. אם אבדה, מחק וצור מחדש |
| האתר אינו נטען | בדוק את מצב האפליקציה במסך הניהול לפני שמאשימים את הלקוח |

**אל תיצור אפליקציה שנייה.** יש אפליקציה אחת שמשרתת את כל לקוחות הפרויקט, וההפרדה
היא ברמת הנתונים. פריסה שנייה תיצור שתי מערכות ושתי סיסמאות מנהל.
