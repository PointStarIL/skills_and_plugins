# מבנה ה-JSON של השאלון

## תוכן עניינים

- הצורה הכללית
- שדות הפרק
- שדות השאלה
- סוגי השאלות
- תצוגה מותנית
- מה המנוע מוסיף בעצמו
- דוגמה שלמה
- בדיקה לפני פריסה

## הצורה הכללית

השאלון הוא **מערך של פרקים**. אין עוטף, אין מפתח `sections` ואין מטא-דאטה בתוך
המערך. המטא-דאטה נשלחת כשדות נפרדים בקריאת ה-API.

```json
[ { פרק }, { פרק }, { פרק } ]
```

## שדות הפרק

| שדה | חובה | תיאור |
|---|---|---|
| `id` | כן | מזהה קצר באנגלית, ייחודי בשאלון. למשל `s1`, `c_hearing` |
| `he` | כן | כותרת הפרק בעברית |
| `en` | כן | כותרת הפרק באנגלית |
| `introHe` | לא | פסקת פתיחה קצרה בעברית |
| `introEn` | לא | אותה פסקה באנגלית |
| `questions` | כן | מערך שאלות |

**המלצה:** פרק שנולד מעילה מקבל `introHe` שמסביר בלשון יומיומית מה הפרק בודק. לא
"פרק זה בוחן את יסודות עילת השימוע", אלא "כמה שאלות על מה שקרה לפני שנאמר לך
שהעבודה מסתיימת".

## שדות השאלה

| שדה | חובה | תיאור |
|---|---|---|
| `id` | כן | מזהה ייחודי בשאלון. **אל תשתמש בסיומת `__more`**, היא שמורה למנוע |
| `type` | כן | אחד מהסוגים שלהלן |
| `he` | כן | נוסח השאלה בעברית |
| `en` | כן | נוסח השאלה באנגלית |
| `hintHe` | לא | הבהרה קצרה מתחת לשאלה |
| `hintEn` | לא | אותה הבהרה באנגלית |
| `options` | לפי הסוג | מערך `{ value, he, en }` |
| `showIf` | לא | תצוגה מותנית, ראה להלן |

## סוגי השאלות

| `type` | מה מוצג | מתי להשתמש |
|---|---|---|
| `text` | שורת טקסט | שם, מקום, פרט קצר |
| `long` | תיבת טקסט | תיאור, השתלשלות, ציטוט |
| `date` | בורר תאריך | תאריך מדויק |
| `number` | מספר | סכום, שיעור, כמות |
| `yesno` | כן / לא / איני זוכר | **שאלת שער.** זה הסוג המרכזי בשאלון הזה |
| `choice` | בחירה אחת מרשימה | שער עם יותר משתי אפשרויות |
| `multi` | בחירה מרובה | רשימת פריטים, למשל אילו ראיות קיימות |

`yesno` אינו דורש `options`, המנוע מספק אותן. `choice` ו-`multi` דורשים `options`.

## תצוגה מותנית

`showIf` פותח שאלה רק כשהתשובה לשאלה אחרת מתאימה.

```json
{ "showIf": { "id": "s3_transfer", "equals": ["yes"] } }
```

- `id` הוא מזהה שאלת השער, שחייבת להופיע **לפני** השאלה המותנית באותו פרק.
- `equals` הוא מערך ערכים. די באחד מהם.
- לשאלת `yesno` הערכים הם `yes`, `no`, `dk`.
- לשאלת `choice` הערכים הם ה-`value` שהגדרת.

**זו הדרך לקיים את כלל אין שאלה מכוונת.** שער ניטרלי, פתוח מותנה.

## מה המנוע מוסיף בעצמו

**אל תכתוב את אלה ל-JSON:**

1. בסוף כל פרק, שאלה פתוחה במזהה `<id הפרק>__more`: "יש עוד משהו בנושא הפרק הזה
   שלא נשאלת עליו?"
2. בסוף השאלון, פרק שלם במזהה `zz_completion` בכותרת "מה שלא נשאלת עליו", עם ארבע
   שאלות פתוחות ופתיח שמסביר שהשאלון נכתב מהמסמכים ולא ממה שהלקוח יודע.

המנוע מוסיף אותם לכל שאלון, ופעולתו אידמפוטנטית. שכפול שלהם ייצור שאלות כפולות
על המסך.

## דוגמה שלמה

```json
[
  {
    "id": "s1",
    "he": "פרטי ההעסקה",
    "en": "Employment details",
    "introHe": "כמה שאלות על מקום העבודה והתקופה.",
    "introEn": "A few questions about the workplace and the period.",
    "questions": [
      {
        "id": "s1_employer",
        "type": "text",
        "he": "מה השם המדויק של החברה שהעסיקה אותך, כפי שהוא מופיע בתלוש?",
        "en": "What is the exact name of the company that employed you, as it appears on your payslip?"
      },
      {
        "id": "s1_start_check",
        "type": "yesno",
        "he": "בתלושים רשום שהתחלת לעבוד ב-16.2.26. האם זה נכון?",
        "en": "Your payslips show you started on 16.2.26. Is that correct?",
        "hintHe": "אם התאריך אינו נכון, כתוב את הנכון בשאלה הבאה.",
        "hintEn": "If the date is wrong, write the correct one in the next question."
      },
      {
        "id": "s1_start_real",
        "type": "date",
        "he": "מה התאריך הנכון שבו התחלת לעבוד?",
        "en": "What is the correct date you started working?",
        "showIf": { "id": "s1_start_check", "equals": ["no", "dk"] }
      }
    ]
  },
  {
    "id": "c_hearing",
    "he": "מה קרה לפני שנאמר לך שהעבודה מסתיימת",
    "en": "What happened before you were told the work was ending",
    "questions": [
      {
        "id": "c_hearing_invited",
        "type": "yesno",
        "he": "האם זומנת לשיחה כלשהי לפני שנאמר לך שהעבודה מסתיימת?",
        "en": "Were you invited to any meeting before you were told the work was ending?"
      },
      {
        "id": "c_hearing_detail",
        "type": "long",
        "he": "תאר את השיחה: מתי התקיימה, מי נכח, ומה נאמר בה.",
        "en": "Describe the meeting: when it took place, who was present, and what was said.",
        "showIf": { "id": "c_hearing_invited", "equals": ["yes"] }
      }
    ]
  }
]
```

## בדיקה לפני פריסה

עבור על הרשימה הזו לפני שאתה שולח את ה-JSON:

1. כל `id` ייחודי בכל השאלון, לא רק בתוך הפרק.
2. אף `id` אינו מסתיים ב-`__more`, ואין פרק במזהה `zz_completion`.
3. כל `showIf` מפנה למזהה שקיים ומופיע לפניו.
4. לכל `choice` ולכל `multi` יש `options` לא ריק.
5. לכל שאלה ולכל פרק יש גם `he` וגם `en`.
6. אין בשאלון תעודת זהות, מספרי חשבון, שמות ילדים או מידע רפואי.
7. אין מקף ארוך באף מחרוזת.
8. עברת על כל שאלה ושאלת: אפשר לענות עליה "לא קרה"? אם לא, היא מכוונת.
