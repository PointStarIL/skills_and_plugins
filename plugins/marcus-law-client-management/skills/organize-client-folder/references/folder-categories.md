# קטגוריות תיקיות ומוסכמת שמות

פירוט מלא של סוגי המסמכים בתיק לקוח מהסיוע המשפטי, והתיקייה שאליה כל אחד שייך.
למוסכמת שמות הקבצים ראה את שלב 3 ב-SKILL.md.

## תוכן עניינים

- מה הולך לאיזו תיקייה

### מה הולך לאיזו תיקייה

**01 - רפואי**:
- סיכומי ביקור רופא משפחה / מומחה (אורתופד, נוירולוג, פסיכיאטר, וכד')
- שחרור מבית חולים / מיון
- תוצאות בדיקות (דם, הדמיה, MRI, CT)
- תעודות מחלה / אישור אי כושר
- חוות דעת רפואיות (פרטיות או של מומחה מטעם בית הדין)
- מרשמים, אם הם מתעדים מצב כרוני

**02 - ביטוח לאומי**:
- תביעות שהוגשו (נכות כללית, נכות מעבודה, אבטלה, הבטחת הכנסה)
- מכתבי תשובה והחלטות מב"ל
- פרוטוקולי ועדות רפואיות (ועדה ראשונה, ערר, רשות)
- החלטות פקיד תביעות
- אישורים על תקופות אכשרה
- טפסי בל/250, בל/200 וכד'

**03 - מעסיק ועבודה**:
- חוזה עבודה / כתב מינוי
- תלושי שכר (אחרון לפני האירוע + לאחור 12 חודשים אם יש)
- מכתב פיטורים / הודעה על סיום עבודה
- שיחת שימוע (פרוטוקול, זימון)
- אישור העסקה
- טופס 161 / 161א / טופס 100
- התכתבויות עם המעסיק

**04 - בית דין / בית משפט**:
- כתב תביעה / כתב הגנה / כתב תשובה
- פרוטוקולים מדיונים
- החלטות ביניים
- פסקי דין
- צווים
- טפסים פרוצדורליים (טופס 1, בקשת רשות להתגונן וכד')
- חוות דעת מומחים שהוגשו

**05 - רשויות נוספות**:
- מס הכנסה (שומות, החזרים, אישורים)
- רשות האכיפה (תיקי הוצל"פ, עיקולים)
- מע"מ
- משטרה / תלונות
- רשם החברות / רשם השותפויות

**06 - אישי ופיננסי**:
- צילום תעודת זהות + ספח
- דפי בנק
- חוזה שכירות / חוזה רכישה
- תעודת לידה / נישואין / גירושין
- אישורי הכנסה
- דוחות אקטואריים פרטיים

**07 - התכתבויות**:
- מיילים בין הלקוח למשרד / למעסיק / לב"ל
- מכתבי ב"כ קודם
- מכתבים מהסיוע המשפטי
- מסרונים בצילום מסך (אם רלוונטי)

**00 - סיכום וניתוח**:
- מסמך הסיכום DOCX שהסקיל יוצר (תוצר סופי)
- כל מסמך עבודה / רשימת משימות שמופק תוך כדי

> **כלל זהב**: כשמסמך גבולי (למשל: חוות דעת רפואית פרטית, רפואי או בית דין?), שאל
> את עצמך **מי הזמין אותה ולשם מה**. חוות דעת שהוזמנה לתביעה בבית דין → 04. חוות
> דעת מרופא משפחה למעקב כללי → 01.
