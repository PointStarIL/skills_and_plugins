# מסמך הסיכום

המבנה המלא של מסמך סיכום תיק הלקוח, חמשת חלקיו, ואופן בנייתו.

## תוכן עניינים

- מבנה מסמך הסיכום

### מבנה מסמך הסיכום

המסמך מחולק לחמישה חלקים. גם אם חלק מסוים ריק (למשל אין מסמכי בית דין), דלג עליו,
אל תכלול חלק ריק.

```
סיכום תיק לקוח, [שם הלקוח]
תאריך הפקה: [היום]
מקור התיק: סיוע משפטי
תחום: [דיני עבודה / נכות / ביטוח לאומי / וכו']

═══════════════════════════════════════════════════════════════

חלק א': רקע ועובדות מרכזיות

תקציר תמציתי בן 3-6 שורות שמסביר את הסיפור: מי הלקוח, מה קרה, מתי, מה הסעד
המבוקש. אם אין מספיק מידע מהמסמכים לבנות את הסיפור, ציין זאת במפורש ("דרוש
תחקור עם הלקוח כדי להשלים: X, Y, Z").
```
