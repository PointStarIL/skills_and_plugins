# Appeal Case Organizer, ארגון תיקי ערר

סקיל זה מבצע ארגון מלא של תיקיות ערר (היטל השבחה / רישוי) בצורה אוטומטית.
התהליך כולל זיהוי מסמכים, שינוי שמות, מיון לתיקיות, חילוץ נספחים, פיצול PDF ויצירת סיכום.

---

## סקירת התהליך

התהליך מורכב מ-3 שלבים עיקריים שמבוצעים ברצף:

1. **זיהוי ומיון**, קריאת כל PDF, זיהוי סוג המסמך, שינוי שם לפי תוכן+תאריך, העברה לתת-תיקייה מתאימה
2. **חילוץ נספחים ופיצול**, זיהוי נספחים מוטמעים בכתבי טענות, פיצול פיזי ל-PDF נפרדים
3. **יצירת סיכום**, מסמך DOCX מסכם עם פירוט כל המסמכים, מיקומם ותוכנם

---

## שלב 1: זיהוי, שינוי שמות ומיון

### מבנה התיקיות

צור את תתי-התיקיות הבאות בתיקייה הראשית:

```
תיקיית ערר/
├── מסמכי ערר/          ← כתבי טענות עיקריים (ערר, תשובה, שומות, תגובות)
├── מסמכים מנהליים/     ← בקשות, החלטות, הזמנות, הודעות
├── פרוטוקולים/         ← פרוטוקולי דיון והחלטות מדיונים
└── ניתוח מסמכים/       ← מסמכי סיכום ועבודה שהסקיל יוצר
```

### כיצד לזהות סוג מסמך

קרא את 2-3 העמודים הראשונים של כל PDF באמצעות הכלי Read (עם pages parameter).
סווג לפי הכללים הבאים:

**מסמכי ערר**, המסמכים המהותיים של התיק:
- כתב ערר (מוגש ע"י העורר/שמאי, מכיל "ערר" או "כתב ערר" בכותרת)
- כתב תשובה (מוגש ע"י הוועדה המקומית, מכיל "תשובה" או "כתב תשובה")
- שומה נגדית / שומת מקרקעין (מסמך שמאי עם הערכות שווי)
- תגובות הדדיות (תגובת העורר / תגובת המשיבה, מסמכים מהותיים שמתייחסים לטענות)

**מסמכים מנהליים**, ניהול ההליך:
- בקשות (להארכת מועד, לפטור, לצירוף מסמכים וכד')
- החלטות ביניים (תגובה לבקשות, אישורים, דחיות)
- הודעות (פתיחת תיק, ייצוג, שינוי מועד)
- הזמנות לדיון
- טיוטות החלטה
- הודעות אימייל (.msg)

**פרוטוקולים**:
- פרוטוקול דיון (תמליל של ישיבה)
- פרוטוקול + החלטה (מסמך חתום שכולל גם את ההחלטה)

### מוסכמת שמות קבצים

שנה את שם כל קובץ לפי הפורמט:

```
[סוג המסמך] - [תאריך בפורמט DD.MM.YY].pdf
```

דוגמאות:
- `כתב ערר - 18.05.25.pdf`
- `החלטה - בקשה להארכת מועד - 09.03.25.pdf`
- `שומה נגדית (אבנר גרון) - 27.05.25.pdf`
- `פרוטוקול דיון - 19.02.26.pdf`
- `בקשה לפטור מהגשת שומה נגדית - 28.04.25.pdf`

כללים:
- התאריך הוא תאריך הגשה/קבלה של המסמך (חפש חותמת "התקבל" או תאריך בכותרת)
- אם יש שם שמאי או גורם רלוונטי, הוסף בסוגריים: `שומה נגדית (אבנר גרון)`
- אם יש החלטה שמתייחסת לבקשה ספציפית, ציין: `החלטה - בקשה לפטור - 30.04.25.pdf`
- קבצי .msg נשארים עם הסיומת המקורית

### ביצוע ההעברה

1. ודא שכל תתי-התיקיות קיימות
2. העבר (copy) כל קובץ לתיקייה המתאימה עם השם החדש
3. לאחר אימות שכל הקבצים הועתקו בהצלחה, מחק את הקבצים המקוריים מהתיקייה הראשית
4. השתמש ב-`mcp__cowork__allow_cowork_file_delete` כדי לקבל הרשאת מחיקה

> **חשוב:** אם יש תיקיות קיימות בתיקייה הראשית (כמו "כתבי בי-דין"), השאר אותן כמו שהן, אל תמחק ואל תשנה תיקיות שכבר קיימות.

## שלב 2: חילוץ נספחים ופיצול PDF

לאחר שכל הקבצים ממוינים, עבור על כל מסמך בתיקיית **מסמכי ערר** וחפש נספחים מוטמעים.

### כיצד לזהות נספחים

קרא את כל העמודים של כל מסמך בתיקיית מסמכי ערר. חפש:
- שינוי פתאומי בפורמט/עיצוב (למשל: מעמוד טקסט לסריקה של מסמך ישן)
- כותרת שונה או לוגו שונה (למשל: עמוד שמתחיל בלוגו עירייה, או בכותרת "שומת מקרקעין")
- חותמות וחתימות שמסמנות סוף מסמך ותחילת נספח
- ציון מפורש: "מצ"ב נספח", "רצ"ב", "נספח א'", "נספח 1"

### סוגי נספחים נפוצים

בכתבי ערר ותשובה תמצא לרוב:
- שומות מקרקעין (שומת השבחה, שומה נגדית)
- החלטות ועדות (ועדה מקומית, ועדת ערר)
- מדיניות מהנדס העיר
- תכניות בניין עיר (תב"ע)
- פרוטוקולים של דיונים קודמים
- שוברי תשלום, קבלות, הודעות זיכוי
- תשריטים ומפות

### תהליך הפיצול

1. **התקן PyPDF2** אם לא מותקן:
   ```bash
   pip install PyPDF2 --break-system-packages
   ```

2. **זהה נקודות פיצול**, לכל מסמך, רשום את מבנה העמודים:
   ```
   כתב ערר (17 עמודים):
   - עמ' 1-3: כתב הערר עצמו
   - עמ' 4: שובר תשלום + קבלה
   - עמ' 5: החלטה
   - עמ' 6-17: שומת השבחה
   ```

3. **צור תת-תיקייה** בתוך מסמכי ערר לכל מסמך שיש לו נספחים:
   ```
   מסמכי ערר/
   ├── כתב ערר + נספחים/
   │   ├── כתב ערר - 18.05.25.pdf          (עמ' 1-3)
   │   ├── נספח - שובר תשלום וקבלה.pdf     (עמ' 4)
   │   ├── נספח - החלטה.pdf                (עמ' 5)
   │   └── נספח - שומת השבחה.pdf           (עמ' 6-17)
   ├── כתב תשובה + נספחים/
   │   ├── כתב תשובה - 18.01.26.pdf        (עמ' 1-8)
   │   └── נספח - שומה (אשר בן ישי).pdf    (עמ' 9-13)
   └── שומה נגדית (אבנר גרון) - 27.05.25.pdf  ← מסמך בודד, ללא נספחים
   ```

4. **שם תת-התיקייה**: `[שם המסמך המקורי ללא סיומת] + נספחים`

5. **שמות קבצי הנספחים**: `נספח - [תיאור התוכן].pdf`

6. **שים לב**: מסמכים שאין להם נספחים (כמו שומה נגדית) נשארים כמו שהם בתיקיית מסמכי ערר, אין צורך ליצור להם תת-תיקייה.

### סקריפט Python לפיצול

השתמש בסקריפט המצורף `scripts/split_pdfs.py` או כתוב סקריפט דומה.
המפתח: הגדר מערך של פיצולים ובצע בפקודה אחת:

```python
from PyPDF2 import PdfReader, PdfWriter
import os

def split_pdf(source_path, output_folder, splits):
    """
    splits = [(start_page, end_page, output_filename), ...]
    Pages are 1-indexed, inclusive.
    """
    reader = PdfReader(source_path)
    os.makedirs(output_folder, exist_ok=True)

    for start, end, name in splits:
        writer = PdfWriter()
        for p in range(start - 1, min(end, len(reader.pages))):
            writer.add_page(reader.pages[p])
        with open(os.path.join(output_folder, name), "wb") as f:
            writer.write(f)
```

## שלב 3: יצירת מסמך סיכום

לאחר הארגון והפיצול, צור מסמך DOCX שמסכם את כל התיק.

### בניית מסמך הסיכום

לבניית הקובץ השתמש במנוע `docx-hebrew-engine` (מחבילת `marcus-law-drafting`) - מקור-האמת לעיצוב מסמכי עברית (RTL, פונט David, שוליים, מספור). למבנה משפטי מובנה ראה גם `legal-docx`. אם החבילה `marcus-law-drafting` אינה מותקנת, בנה DOCX עם python-docx לפי הכללים: פונט David גודל 12, RTL מלא (w:rtl לכל run, w:bidi לפסקה ולסקציה), שוליים 2.54 ס"מ, מרווח שורות 1.5.

### מבנה מסמך הסיכום

```
כותרת: סיכום תיק ערר [מספר ערר]
תאריך: [תאריך הפקה]

1. פרטי התיק
   - מספר ערר
   - שם העורר
   - שם המשיבה
   - נושא הערר

2. מסמכי ערר (טבלה)
   | # | שם המסמך | מיקום | תאריך | תיאור קצר |

3. מסמכים מנהליים (טבלה)
   | # | שם המסמך | מיקום | תאריך | תיאור קצר |

4. פרוטוקולים (טבלה)
   | # | שם המסמך | מיקום | תאריך | תיאור קצר |
```

שמור את מסמך הסיכום בתיקיית `ניתוח מסמכים/` בשם:
```
סיכום תיק ערר [מספר].docx
```

## טיפים וכללי אצבע

- **קרא לפני שתסווג**: תמיד קרא לפחות 2-3 עמודים ראשונים לפני שאתה מחליט מה סוג המסמך. שמות קבצים מקוריים לעתים מטעים.
- **תאריכים**: חפש חותמת "התקבל" בפינה העליונה, או תאריך בכותרת המסמך. אם אין תאריך ברור, השתמש בתאריך מטאדאטה של הקובץ.
- **מסמכים כפולים**: אם יש שני עותקים של אותו מסמך (אחד חתום ואחד לא), שמור את שניהם עם תוספת "(חתום)" בשם.
- **קבצים שאינם PDF**: קבצי .msg (אימייל), העבר כמות שהם לתיקיית מסמכים מנהליים. קבצי Word/Excel, קרא את התוכן וסווג בהתאם.
- **תיקיות קיימות**: אל תמחק ואל תשנה תיקיות שכבר קיימות בתיקייה הראשית לפני שהתחלת. הן עשויות להכיל מסמכים שהמשתמש ארגן ידנית.
- **מסמכים שלא ניתן לזהות**: אם לא ברור מה המסמך, שאל את המשתמש לפני שתמיין.
- **גודל תיק**: אם יש יותר מ-30 קבצים, עבוד ב-batches של 10 כדי לא לאבד מיקוד.

## תלויות

- **PyPDF2**: לפיצול קבצי PDF (`pip install PyPDF2 --break-system-packages`)
- **מנוע docx-hebrew-engine** (חבילת `marcus-law-drafting`): לבניית מסמך הסיכום בעברית; `legal-docx` למבנה משפטי
- **כלי Read**: לקריאת תוכן PDF (עם פרמטר pages)
- **כלי Bash**: להעברת קבצים ויצירת תיקיות
