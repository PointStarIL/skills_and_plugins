# marcus-law-research

חבילת מחקר משפטי ממקורות ראשוניים. כוללת סקיל אחד.

## סקיילים בחבילה

- `search-open-law-book` — חיבור ישיר ל[ספר החוקים הפתוח](https://he.wikisource.org/wiki/ספר_החוקים_הפתוח) בוויקיטקסט העברי, לשליפת נוסח מדויק של חוקים ותקנות ישראליים. כל שליפה חוזרת עם מראה מקום, מספר גרסה ותאריך גרסה.

## למה זה קיים

ציטוט לשון חוק מזיכרון המודל הוא מקור עיקרי להזיות בעבודה משפטית. הסקיל הזה הופך את החקיקה למקור טקסטואלי נשלף: המודל מריץ שאילתה מול ה-API של ויקיטקסט ומצטט מהפלט, לא מהזיכרון. הכלל הזה כתוב בגוף ה-`SKILL.md` ואוכף את עצמו בזמן השימוש.

## הכלי

`scripts/wikilaw.py` — Python 3.8+, ספריית תקן בלבד, בלי תלויות חיצוניות ובלי מפתח API.

| פקודה | מה היא עושה |
|---|---|
| `search` | מאתר את שם הדף המדויק בוויקיטקסט |
| `toc` | תוכן עניינים: פרקים, סימנים, ועם `--sections` גם מספרי הסעיפים |
| `sec` | נוסח מלא של סעיף, עם מיקומו בפרק ובסימן ועם תיקוני החקיקה שחלו עליו |
| `grep` | חיפוש regex בתוך חוק, מוצג לפי סעיפים |
| `fulltext` | חיפוש נוסח מדויק בכל ספר החוקים |
| `text` | נוסח מלא של דף |

בווינדוס יש להריץ `python`: השם `python3` משויך שם לקיצור-הדרך של חנות Microsoft, שיוצא בלי פלט ובלי שגיאה.

```bash
python3 skills/search-open-law-book/scripts/wikilaw.py sec "חוק הביטוח הלאומי" 209
python3 skills/search-open-law-book/scripts/wikilaw.py grep "חוק הביטוח הלאומי" "ועדה רפואית לעררים"
python3 skills/search-open-law-book/scripts/wikilaw.py fulltext "דרגת אי כושר להשתכר"
```

### איך זה עובד

דפי ספר החוקים הפתוח בנויים בתבניות ויקי מובנות (`{{ח:סעיף|118|קביעת דרגת נכות|תיקון: תשנ״ח־2}}`, `{{ח:קטע2}}`, `{{ח:תת|(א)}}`). הכלי מושך את ה-wikitext הגולמי דרך ה-API של MediaWiki, מפרק אותו לעץ של פרקים, סימנים וסעיפים, ומרנדר את התבניות לטקסט קריא. הרינדור מסיר עיצוב אך אינו משנה מילים, כולל המקפים העבריים והפיסוק של הנוסח המקורי. `--raw` מציג את ה-wikitext הגולמי להשוואה.

### מטמון

`~/.wikilaw-cache`, תוקף שבוע. `--refresh` מושך גרסה עדכנית. משתני סביבה: `WIKILAW_CACHE`, `WIKILAW_TTL`.

## בדיקות

```bash
cd skills/search-open-law-book
python3 tests/test_wikilaw.py                      # 20 בדיקות, ללא רשת
WIKILAW_ONLINE=1 python3 tests/test_wikilaw.py     # 24 בדיקות, כולל רשת
```

הבדיקות ללא הרשת רצות מול fixture של wikitext ומאמתות את הפענוח: זיהוי סעיפים, כותרות ותיקונים, שרשרת פרק-סימן, תבניות מקוננות, וכן שהרינדור אינו משנה מילים. בדיקות הרשת מאמתות מול ויקיטקסט שהחיפוש, המטא-דאטה ונוסח סעיף ידוע חוזרים כמצופה. אין תלויות חיצוניות, `unittest` בלבד.

הרצת בדיקות הרשת ב-CI תיכשל מדי פעם בשל הגבלת קצב של ויקימדיה (HTTP 429). מומלץ להריץ ב-CI רק את הבדיקות המקומיות.

## מגבלות

- ויקיטקסט הוא מקור **לא רשמי**. נוסח שנכנס לכתב בי-דין או להחלטה יש לאמת מול רשומות או נבו לפני הגשה.
- ייתכן פיגור של שבועות בין פרסום תיקון ברשומות לבין עדכון הדף. תאריך הגרסה בפלט מאפשר לזהות זאת.
- ספר החוקים הפתוח מכיל חקיקה ראשית ומשנית בלבד. אין בו פסיקה, חוזרי רשויות, או הסכמים (כמו הסכם הניידות).
- ה-API של ויקימדיה מגביל קצב. הכלי מבצע עד שישה ניסיונות עם השהיה מתגברת.
