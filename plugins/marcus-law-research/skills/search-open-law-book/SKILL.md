# ספר החוקים הפתוח — חיפוש ישיר

כלי לשליפת נוסח מדויק של חקיקה ישראלית מתוך [ספר החוקים הפתוח](https://he.wikisource.org/wiki/ספר_החוקים_הפתוח) בוויקיטקסט העברי, דרך ה-API של MediaWiki.

## עקרון מנחה

הכלי הזה הוא **מקור טקסטואלי**, לא זיכרון של המודל. כל ציטוט חקיקה שמופיע בתשובה חייב להגיע מפלט של הכלי או ממסמכי הפרויקט. אין לצטט לשון חוק מהזיכרון, אין להשלים סעיפים חסרים, ואין לנסח מחדש את לשון החוק אלא אם התבקש במפורש.

## הפעלה

הסקריפט הוא Python 3 בלבד, בלי תלויות חיצוניות:

> **בווינדוס להריץ `python` ולא `python3`.** שם `python3` משויך שם לקיצור-הדרך של חנות Microsoft,
> שיוצא בלי פלט ובלי שגיאה — הפקודה תיראה כאילו הצליחה ולא תחזיר דבר.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" <פקודה> [ארגומנטים]
```

### 1. חיפוש חוק או תקנה

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" search "תקנות הביטוח הלאומי קביעת דרגת נכות" --limit 8
```

מחזיר שמות דפים מדויקים בוויקיטקסט. **תמיד להתחיל מכאן** כשלא יודעים את שם הדף המדויק, כי שאר הפקודות דורשות את השם המלא כפי שהוא בוויקיטקסט (למשל `תקנות הביטוח הלאומי (ביטוח נכות) (קביעת אחוזי נכות רפואית, מינוי ועדות לעררים והוראות שונות)`).

### 2. תוכן עניינים

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" toc "חוק הביטוח הלאומי"
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" toc "חוק הביטוח הלאומי" --sections   # כולל כל מספרי הסעיפים
```

### 3. שליפת סעיף — הפקודה המרכזית

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" sec "חוק הביטוח הלאומי" 209
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" sec "חוק הביטוח הלאומי" 118
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" sec "תקנות הביטוח הלאומי (שיקום מקצועי)" 5
```

הפלט כולל: שם החוק, המיקום בפרק ובסימן, כותרת הסעיף, תיקוני החקיקה שחלו עליו, הנוסח המלא עם סעיפי המשנה, וקישור + תאריך גרסה.

מספר סעיף עם אות (`57א`, `127כב`) נתמך. אם הסעיף לא נמצא, הכלי מציע מספרים קרובים.

### 4. חיפוש בתוך חוק לפי סעיפים

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" grep "חוק הביטוח הלאומי" "אי־כושר|אי כושר להשתכר"
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" grep "חוק הביטוח הלאומי" "ועדה רפואית לעררים" --full
```

`--full` מדפיס את הסעיף השלם ולא רק את השורות התואמות. הביטוי הוא regex של Python.

### 5. חיפוש נוסח מדויק בכל ספר החוקים

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" fulltext "דרגת אי כושר להשתכר"
```

מאתר בכל החקיקה אילו חוקים ותקנות מכילים ביטוי מסוים. שימושי כשלא ידוע איזה דבר חקיקה מסדיר סוגיה.

### 6. נוסח מלא של דף

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/search-open-law-book/scripts/wikilaw.py" text "תקנות הביטוח הלאומי (הכשרת רופא המוסמך לקבוע דרגת נכות)"
```

**זהירות:** חוקים גדולים כמו חוק הביטוח הלאומי הם מעל 600 אלף תווים. אין להריץ `text` על חוק גדול; להשתמש ב-`sec` או ב-`grep`.

## דגלים כלליים

- `--refresh` — עוקף את המטמון ומושך גרסה עדכנית מוויקיטקסט.
- מטמון: `~/.wikilaw-cache`, תוקף שבוע. ניתן לשנות עם `WIKILAW_CACHE` ו-`WIKILAW_TTL`.

## כללי ציטוט בתשובה

1. לצטט **מילה במילה** מפלט הכלי, כולל סימני הפיסוק והמקפים של הנוסח המקורי.
2. לציין תמיד מראה מקום: שם החוק המלא, מספר הסעיף, וסעיף המשנה.
3. לצרף את שורת המקור שהכלי מחזיר (קישור + תאריך הגרסה) בסוף התשובה תחת "מקורות".
4. ויקיטקסט הוא מקור **לא רשמי**. בנוסח שהולך לכתב בי-דין או להחלטה, לציין שיש לאמת מול רשומות או נבו לפני הגשה.
5. אם הכלי לא מצא את הסעיף — לומר זאת. לא להשלים מהזיכרון.

## מגבלות ידועות

- ויקיטקסט מוגבל לחקיקה ראשית ומשנית. אין בו פסיקה, חוזרי מוסד לביטוח לאומי, או הסכמים (כמו הסכם הניידות) — אלה נמצאים במסמכי הפרויקט.
- ייתכן פיגור של שבועות בין פרסום תיקון ברשומות לבין עדכון הדף. תאריך הגרסה בפלט מאפשר לזהות זאת.
- הכלי מנקה תבניות עיצוב של ויקיטקסט אך אינו משנה מילים. להשוואה לנוסח הגולמי: `--raw`.
- ה-API של ויקימדיה מגביל קצב. הכלי מבצע ניסיונות חוזרים עם השהיה; במקרה של שגיאת 429 להמתין ולנסות שוב.
