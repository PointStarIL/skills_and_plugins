# marcus-law-appeal-committee

חבילת ועדת ערר לתכנון ובנייה: כל מה שקשור לטיפול בעררים ולכתיבת החלטות ועדת הערר — חילוץ טענות, ארגון תיקי ערר, וכתיבה/ארגון/אימות/ביקורת של החלטות. כוללת 7 סקיילים וסוכן.

## סקיילים בחבילה

חומרי הערר:
- extract-appeal-claims — חילוץ טענות, עובדות ונתונים מכתבי בי-דין
- organize-appeal-folder — ארגון אוטומטי של תיקיית ערר

כתיבת ההחלטה:
- write-appeal-decision — ניסוח והשלמת פסקאות "דיון והכרעה"
- reorder-decision-sections — סידור-מחדש של פרק הדיון לסדר לוגי
- verify-decision-unchanged — אימות שימור אחרי סידור-מחדש
- review-decision-draft — ביקורת מבנית על טיוטת החלטה
- decision-structure-template — תבנית/שלד מבנה ההחלטה (ייעוץ-מבני)

## סוכן

- decision-reorganizer — מתזמר את זרימת ארגון/כתיבת ההחלטה
