# תחביר הסוגריים הזוויתיים (<>) לסימון הוראות בטיוטה

המשתמש משתמש בסוגריים זוויתיים (<>) כדי לסמן בטיוטת DOCX מקומות שבהם נדרשת השלמה או ניסוח מחדש על ידי הסקיל. מסמך זה מתאר את התחביר ואת אופן הפירוש הנכון של כל סוג הוראה.

## כללי בסיס

1. **תחילת הוראה:** התו "<" פותח הוראה.
2. **סוף הוראה:** התו ">" סוגר הוראה.
3. **תוכן ההוראה:** טקסט חופשי בעברית, בלשון פנייה אל הסקיל ("פה תכניס", "תנסח מחדש").
4. **היקף ההוראה:** ההוראה יכולה להתפרש על פני פסקה אחת, או על פני מספר פסקאות (במקרה זה, ה-< נמצא בתחילת הפסקה הראשונה וה-> בסוף הפסקה האחרונה).

## סוגי הוראות נפוצים

### סוג 1: כתיבת פסקה חדשה (יש מקור כתיבה ריק)

הפסקה ריקה ויש בה רק הוראה. דוגמה:

```
99. עצימות השימוש החורג: <פה תפקידך לנסח כמה פסקאות איך ועדת הערר רואה את היקף השימוש במסחר לסופר-מרקט בנסיבות העניין ...>
```

**פירוש:** יש לכתוב פסקאות חדשות מאפס, על-פי ההוראה. אין תוכן קיים שיש לעבד.

### סוג 2: ניסוח מחדש של פסקאות קיימות

ההוראה היא "תנסח מחדש" או "תערוך" ועוטפת מספר פסקאות שכבר כתובות. דוגמה:

```
103. <אכן תכנית מי/000/א הינה משנת 1995...
104. עם זאת, מעת לעת ניתן למצוא הצדקה לאישור שימוש חורג...
105. ...
106. ואולם, לא כל מקרה שבו מקודמת תכנית מסדירה מצדיק...>
```

**פירוש:** המשתמש כתב את התוכן הבסיסי. תפקיד הסקיל לעבד אותו (לערוך סגנון, להחליק, לקצר אם נדרש), אך לשמור על כל הטיעונים והעובדות.

### סוג 3: הרחבה של פסקה קצרה

ההוראה היא "תרחיב" או "תפרט" ועוטפת פסקה תמציתית או רעיון מנוסח בקצרה. דוגמה:

```
130. עקרון השקיפות: <תנסח מחדש את הפסקה הזאת ותרחיב אותה> כפי שפורט הבקשה מושא הערר פורסמה לידוע הציבור...
```

**פירוש:** המשתמש כתב רעיון או נתון בקצרה. תפקיד הסקיל לפתח את הרעיון לכדי פסקאות מלאות, תוך שמירה על כל העובדות שכבר נכתבו.

### סוג 4: הוספת נושא מסוים בתוך פסקה קיימת

ההוראה היא "פה אני רוצה שנוסיף גם" ועוטפת תוכן ספציפי שצריך לשבץ בתוך פסקה קיימת. דוגמה:

```
128. <פה אני רוצה שנוסיף גם את מה שהזכרנו בתחילת הדיון שבעצם ניוד השטחים המבוקשים הופך חלק גדול מהמבנה...>
```

**פירוש:** המשתמש מציין נושא שצריך להופיע במסמך, ומספק את העובדות. תפקיד הסקיל לשבץ את הנושא בנקודה הנכונה במסמך, בצורה שמתחברת לפסקאות סביבה.

### סוג 5: הפניה לפסקה אחרת בטיוטה

ההוראה כוללת הפניה ("תכניס לתוך עצימות השימוש החורג"). דוגמה:

```
100. היקף השימוש החורג: <תכניס לתוך עצימות השימוש החורג>
```

**פירוש:** התוכן של הסעיף הזה צריך להישבץ בתוך סעיף אחר. לסקיל אסור להשאיר את הסעיף ריק; עליו להעביר את התוכן הרלוונטי לסעיף שצוין.

## נהלי עבודה עם ההוראות

### שלב 1: זיהוי כל ההוראות

הסקיל מריץ את `scripts/extract_instructions.py` שמייצר טבלה של כל ההוראות במסמך:

| # | מספר פסקה | פסקת הוראה (קטע) | סוג ההוראה |
|---|---|---|---|
| 1 | 99 | "פה תפקידך לנסח..." | סוג 1 |
| 2 | 100 | "תכניס לתוך עצימות..." | סוג 5 |
| 3 | 103-122 | "תנסח מחדש את הפסקאות הבאות..." | סוג 2 |
| ... | ... | ... | ... |

### שלב 2: תכנון מפורש למשתמש

הסקיל מציג את הטבלה למשתמש, יחד עם הצעה לכתיבה לכל בלוק. המשתמש מאשר או מתקן.

### שלב 3: כתיבה לפי הסדר

הסקיל כותב כל בלוק בנפרד. אם מדובר במספר פסקאות שעולות בקנה אחד (סוג 2), הסקיל מנסח אותן כיחידה אחת.

### שלב 4: שילוב לטיוטה

הסקיל יוצר DOCX חדש (טיוטה N+1) שמכיל את הטיוטה המקורית עם הפסקאות החדשות במקום סימוני ההוראה. ההוראות עצמן (הטקסט בין <>) מוסרות.

## טיפים לזיהוי

- **טקסט בעברית בלבד.** סוגריים זוויתיים בעברית הם הסימן.
- **אסור להחליף.** אם בטיוטה יש שימוש בסוגריים זוויתיים כסימני יחסות (למשל "<טקסט אחר>" שאינו הוראה למשתמש), הסקיל צריך לזהות זאת ולא להחליפו.
- **רעננות:** הוראות יכולות להתעדכן בין טיוטה לטיוטה. הסקיל יבחן בכל פעם מחדש.
