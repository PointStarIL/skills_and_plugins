# Appeal Case Organizer, ארגון תיקי ערר

סקיל זה מבצע ארגון מלא של תיקיות ערר (היטל השבחה / רישוי) בצורה אוטומטית.
התהליך כולל זיהוי מסמכים, שינוי שמות, מיון לתיקיות, הטמעת שכבת טקסט,
חילוץ נספחים, פיצול PDF, ייצוא טקסט טהור ויצירת סיכום.

---

## סקירת התהליך

התהליך מורכב מ-5 שלבים שמבוצעים ברצף. **הסדר חשוב:** מטמיעים את שכבת
הטקסט לפני הפיצול, כדי שכל הנספחים המפוצלים יירשו אותה ולא יידרש OCR פעמיים.

1. **זיהוי ומיון**, קריאת כל PDF (כולל OCR למסמכים סרוקים), זיהוי סוג המסמך, שינוי שם לפי תוכן+תאריך, העברה לתת-תיקייה מתאימה
2. **הטמעת שכבת טקסט**, הפיכת כל קובץ סרוק לקובץ שניתן לחפש בו, לסמן ולהעתיק ממנו
3. **חילוץ נספחים ופיצול**, זיהוי נספחים מוטמעים בכתבי טענות, פיצול פיזי ל-PDF נפרדים
4. **ייצוא טקסט טהור**, קובץ .md לכל מסמך תחת "ניתוח מסמכים/טקסט OCR"
5. **יצירת סיכום**, מסמך DOCX מסכם עם פירוט כל המסמכים, מיקומם ותוכנם

> **מסמכים סרוקים:** רוב קובצי הערר הם סריקות ללא שכבת טקסט. במקרים אלה יש להריץ OCR לפני הסיווג, ראה "OCR למסמכים סרוקים" בשלב 1.

> **הבחנה קריטית:** הרצת `ocr_with_fallback.py` מחזירה טקסט **לתוך הסשן בלבד**. קובץ ה-PDF שנשאר אצל המשתמש עדיין תמונה, ואי אפשר לחפש בו. כדי שהטקסט יהיה בקובץ עצמו חובה להריץ את שלב 2. אל תדווח למשתמש ש"בוצע OCR" בלי להריץ אותו.

## שלב 1: זיהוי, שינוי שמות ומיון

### מבנה התיקיות

צור את תתי-התיקיות הבאות בתיקייה הראשית:

```
תיקיית ערר/
├── מסמכי ערר/          ← כתבי טענות עיקריים (ערר, תשובה, שומות, תגובות)
├── מסמכים מנהליים/     ← בקשות, החלטות, הזמנות, הודעות
├── פרוטוקולים/         ← פרוטוקולי דיון והחלטות מדיונים
└── ניתוח מסמכים/       ← מסמכי סיכום ועבודה שהסקיל יוצר
```

### OCR למסמכים סרוקים

לפני הסיווג, ודא שיש טקסט קריא בכל PDF. מסמכים רבים בתיקי ערר הם סריקות ללא שכבת טקסט, ובלי OCR לא ניתן לסווג אותם, לחלץ תאריך או לזהות נספחים.

**מתי להריץ OCR:** אם קריאת הקובץ עם הכלי Read מחזירה מעט טקסט או ג'יבריש, או אם `pdftotext` מחזיר עמוד ריק, המסמך סרוק. בדיקה מהירה:

```bash
pdftotext -f 1 -l 2 "file.pdf" - | wc -w   # מעט מילים => כנראה סרוק
```

**כיצד להריץ:** השתמש בסקריפט המצורף `scripts/ocr_with_fallback.py`. הוא מריץ קודם OCR מקומי (Tesseract עברית+אנגלית), ואם האיכות נמוכה מסף (ביטחון ממוצע, כמות טקסט, יחס תווים תקינים), נופל אוטומטית ל-API של Mistral OCR.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/organize-appeal-folder/scripts/ocr_with_fallback.py" "file.pdf" --out "file.txt"
```

הסקריפט מדפיס ל-stderr באיזה מנוע נעשה שימוש (`tesseract` או `mistral`) ומדוע נפל. השתמש בטקסט שמתקבל לסיווג, לחילוץ התאריך ולזיהוי הנספחים.

**מפתח Mistral (Infisical):** הסקריפט קורא את מפתח ה-API ושם המודל ממשתני סביבה. הסודות שמורים ב-Infisical תחת פרויקט `2c462576-b125-4279-b0ec-7220dbf51ccf`, סביבה `main`, נתיב `/services/mistral` (מפתחות `API_KEY` ו-`OCR_MODEL`, כרגע `mistral-ocr-4-0`). הרצה עם הזרקת הסודות בזמן ריצה דרך Infisical CLI:

```bash
infisical run --projectId=2c462576-b125-4279-b0ec-7220dbf51ccf --env=main --path=/services/mistral -- \
  python3 "${CLAUDE_PLUGIN_ROOT}/skills/organize-appeal-folder/scripts/ocr_with_fallback.py" "file.pdf" --out "file.txt"
```

הסקריפט תומך גם בשמות `MISTRAL_API_KEY` / `MISTRAL_OCR_MODEL` אם מוגדרים ישירות.

**דרישות:** חבילת השפה העברית ל-Tesseract (`tesseract-ocr-heb`), הספריות `pytesseract`, `pdf2image`, `requests`, ו-`poppler-utils`. הנפילה ל-Mistral דורשת גישה יוצאת לדומיין `api.mistral.ai`. אם אין גישה, הסקריפט מחזיר את תוצאת ה-OCR המקומית עם אזהרה.

### כיצד לזהות סוג מסמך

קרא את 2-3 העמודים הראשונים של כל PDF באמצעות הכלי Read (עם pages parameter). למסמכים סרוקים, השתמש בטקסט שהתקבל מ-OCR (ראה למעלה).
סווג לפי הכללים הבאים:

**מסמכי ערר**, המסמכים המהותיים של התיק:
- כתב ערר (מוגש ע"י העורר/שמאי, מכיל "ערר" או "כתב ערר" בכותרת)
- כתב תשובה (מוגש ע"י הוועדה המקומית, מכיל "תשובה" או "כתב תשובה")
- שומה נגדית / שומת מקרקעין (מסמך שמאי עם הערכות שווי)
- תגובות הדדיות (תגובת העורר / תגובת המשיבה, מסמכים מהותיים שמתייחסים לטענות)

**מסמכים מנהליים**, ניהול ההליך:
- בקשות (להארכת מועד, לפטור, לצירוף מסמכים וכד')
- החלטות ביניים (תגובה לבקשות, אישורים, דחיות)
- הודעות (פתיחת תיק, ייצוג, שינוי מועד)
- הזמנות לדיון
- טיוטות החלטה
- הודעות אימייל (.msg)

**פרוטוקולים**:
- פרוטוקול דיון (תמליל של ישיבה)
- פרוטוקול + החלטה (מסמך חתום שכולל גם את ההחלטה)

### מוסכמת שמות קבצים

שנה את שם כל קובץ לפי הפורמט:

```
[סוג המסמך] - [תאריך בפורמט DD.MM.YY].pdf
```

דוגמאות:
- `כתב ערר - 18.05.25.pdf`
- `החלטה - בקשה להארכת מועד - 09.03.25.pdf`
- `שומה נגדית (אבנר גרון) - 27.05.25.pdf`
- `פרוטוקול דיון - 19.02.26.pdf`
- `בקשה לפטור מהגשת שומה נגדית - 28.04.25.pdf`

כללים:
- התאריך הוא תאריך הגשה/קבלה של המסמך (חפש חותמת "התקבל" או תאריך בכותרת)
- אם יש שם שמאי או גורם רלוונטי, הוסף בסוגריים: `שומה נגדית (אבנר גרון)`
- אם יש החלטה שמתייחסת לבקשה ספציפית, ציין: `החלטה - בקשה לפטור - 30.04.25.pdf`
- קבצי .msg נשארים עם הסיומת המקורית

### ביצוע ההעברה

1. ודא שכל תתי-התיקיות קיימות
2. העבר (copy) כל קובץ לתיקייה המתאימה עם השם החדש
3. לאחר אימות שכל הקבצים הועתקו בהצלחה, מחק את הקבצים המקוריים מהתיקייה הראשית
4. השתמש ב-`mcp__cowork__allow_cowork_file_delete` כדי לקבל הרשאת מחיקה

> **חשוב:** אם יש תיקיות קיימות בתיקייה הראשית (כמו "כתבי בי-דין"), השאר אותן כמו שהן, אל תמחק ואל תשנה תיקיות שכבר קיימות.

## שלב 2: הטמעת שכבת טקסט בקובצי ה-PDF

ה-OCR שהורץ בשלב 1 שירת אותך בלבד: הטקסט הגיע לסשן, אבל קובץ ה-PDF שיישאר
אצל המשתמש הוא עדיין תמונה. בשלב זה מטמיעים שכבת טקסט בלתי נראית מתחת
לסריקה, כך שאפשר לחפש בקובץ, לסמן ולהעתיק ממנו. **המראה של המסמך אינו משתנה.**

**מתי לבצע:** תמיד, על כל קובץ סרוק בתיק, כולל מסמכים מנהליים ופרוטוקולים.

**סדר נכון וחיסכון בזמן:** הרץ את השלב הזה **לפני** הפיצול (שלב 3), על כתב
הערר המלא. הנספחים שיפוצלו ממנו יירשו את שכבת הטקסט אוטומטית. אם תפצל קודם,
תריץ OCR על אותם עמודים פעמיים.

### כיצד להריץ

השתמש בסקריפט המצורף `scripts/embed_text_layer.py` (עוטף `ocrmypdf` עם
Tesseract עברית+אנגלית):

```bash
# כל התיק בבת אחת, החלפה במקום
python3 "${CLAUDE_PLUGIN_ROOT}/skills/organize-appeal-folder/scripts/embed_text_layer.py" \
  "תיקיית ערר" --recursive --in-place

# לתיקיית פלט נפרדת (שימושי כשעובדים בענן ומחזירים למחשב המשתמש)
python3 "${CLAUDE_PLUGIN_ROOT}/skills/organize-appeal-folder/scripts/embed_text_layer.py" \
  "תיקיית ערר" --recursive --out-dir /tmp/ocr
```

הסקריפט מדלג אוטומטית על קבצים שכבר יש בהם שכבת טקסט, מוודא שמספר העמודים
לא השתנה, ומדפיס סיכום של הצלחות, דילוגים וכשלים.

### התקנת התלויות

```bash
pip install ocrmypdf pypdf --break-system-packages
apt-get install -y tesseract-ocr-heb   # חבילת העברית לא תמיד מותקנת
```

### אימות

לפני שממשיכים, ודא שאין קובץ שנשאר ללא טקסט:

```bash
python3 -c "
import glob,os
from pypdf import PdfReader
for f in sorted(glob.glob('תיקיית ערר/**/*.pdf', recursive=True)):
    r=PdfReader(f); w=sum(len((p.extract_text() or '').split()) for p in r.pages)
    print(f'{len(r.pages):4d} עמ | {w:6d} מילים | {os.path.basename(f)}')
"
```

> **על איכות השכבה:** Tesseract בעברית פחות מדויק מ-Mistral OCR. שכבת הטקסט
> טובה דיה לחיפוש וניווט, אבל **אינה מקור לציטוט**. לציטוט מדויק השתמש
> בקובצי ה-md משלב 4, ובכל מקרה אמת מול ה-PDF.

## שלב 3: חילוץ נספחים ופיצול PDF

לאחר שכל הקבצים ממוינים ובעלי שכבת טקסט, עבור על כל מסמך בתיקיית **מסמכי ערר** וחפש נספחים מוטמעים.

### כיצד לזהות נספחים

קרא את כל העמודים של כל מסמך בתיקיית מסמכי ערר. חפש:
- שינוי פתאומי בפורמט/עיצוב (למשל: מעמוד טקסט לסריקה של מסמך ישן)
- כותרת שונה או לוגו שונה (למשל: עמוד שמתחיל בלוגו עירייה, או בכותרת "שומת מקרקעין")
- חותמות וחתימות שמסמנות סוף מסמך ותחילת נספח
- ציון מפורש: "מצ"ב נספח", "רצ"ב", "נספח א'", "נספח 1"

### סוגי נספחים נפוצים

בכתבי ערר ותשובה תמצא לרוב:
- שומות מקרקעין (שומת השבחה, שומה נגדית)
- החלטות ועדות (ועדה מקומית, ועדת ערר)
- מדיניות מהנדס העיר
- תכניות בניין עיר (תב"ע)
- פרוטוקולים של דיונים קודמים
- שוברי תשלום, קבלות, הודעות זיכוי
- תשריטים ומפות

### תהליך הפיצול

1. **התקן PyPDF2** אם לא מותקן:
   ```bash
   pip install PyPDF2 --break-system-packages
   ```

2. **זהה נקודות פיצול**, לכל מסמך, רשום את מבנה העמודים:
   ```
   כתב ערר (17 עמודים):
   - עמ' 1-3: כתב הערר עצמו
   - עמ' 4: שובר תשלום + קבלה
   - עמ' 5: החלטה
   - עמ' 6-17: שומת השבחה
   ```

3. **צור תת-תיקייה** בתוך מסמכי ערר לכל מסמך שיש לו נספחים:
   ```
   מסמכי ערר/
   ├── כתב ערר + נספחים/
   │   ├── כתב ערר - 18.05.25.pdf          (עמ' 1-3)
   │   ├── נספח - שובר תשלום וקבלה.pdf     (עמ' 4)
   │   ├── נספח - החלטה.pdf                (עמ' 5)
   │   └── נספח - שומת השבחה.pdf           (עמ' 6-17)
   ├── כתב תשובה + נספחים/
   │   ├── כתב תשובה - 18.01.26.pdf        (עמ' 1-8)
   │   └── נספח - שומה (אשר בן ישי).pdf    (עמ' 9-13)
   └── שומה נגדית (אבנר גרון) - 27.05.25.pdf  ← מסמך בודד, ללא נספחים
   ```

4. **שם תת-התיקייה**: `[שם המסמך המקורי ללא סיומת] + נספחים`

5. **שמות קבצי הנספחים**: `נספח - [תיאור התוכן].pdf`

6. **שים לב**: מסמכים שאין להם נספחים (כמו שומה נגדית) נשארים כמו שהם בתיקיית מסמכי ערר, אין צורך ליצור להם תת-תיקייה.

### סקריפט Python לפיצול

השתמש בסקריפט המצורף `scripts/split_pdfs.py` או כתוב סקריפט דומה.
המפתח: הגדר מערך של פיצולים ובצע בפקודה אחת:

```python
from PyPDF2 import PdfReader, PdfWriter
import os

def split_pdf(source_path, output_folder, splits):
    """
    splits = [(start_page, end_page, output_filename), ...]
    Pages are 1-indexed, inclusive.
    """
    reader = PdfReader(source_path)
    os.makedirs(output_folder, exist_ok=True)

    for start, end, name in splits:
        writer = PdfWriter()
        for p in range(start - 1, min(end, len(reader.pages))):
            writer.add_page(reader.pages[p])
        with open(os.path.join(output_folder, name), "wb") as f:
            writer.write(f)
```

### אימות הפיצול

סכום עמודי הקבצים המפוצלים חייב להיות זהה למספר העמודים במקור. אם יש פער,
נשמט טווח עמודים; אתר אותו ותקן לפני שממשיכים. דווח את הסכום למשתמש.

### מה עושים עם קובץ המקור

שאל את המשתמש. ברירת המחדל המומלצת: שמור את הקובץ המלא בתוך תת-התיקייה
בשם `[שם המסמך] (מקור מלא) - [תאריך].pdf` כגיבוי, ומחק עותקים כפולים
מיותרים. אם אין הרשאת מחיקה בסביבה שבה אתה עובד, העבר את הקבצים המיותרים
לתיקיית `_to_delete/` בשורש התיק ואמור למשתמש שהוא יכול למחוק אותה.

## שלב 4: ייצוא טקסט טהור (MD)

בנוסף לשכבת הטקסט שבתוך ה-PDF, ייצא לכל מסמך קובץ `.md` בטקסט טהור. שכבת
הטקסט טובה לחיפוש; קובץ ה-md נועד לציטוט מדויק, לקריאה מהירה, ולהזנה של
סקילים אחרים (למשל `extract-appeal-claims`) בלי להריץ OCR מחדש.

### מקור הטקסט

השתמש בטקסט האיכותי ביותר שכבר יש לך, כלומר פלט `ocr_with_fallback.py`
משלב 1 (בדרך כלל Mistral). אל תריץ OCR מחדש רק בשביל השלב הזה.

### מבנה היעד

קובצי ה-md יושבים תחת `ניתוח מסמכים/טקסט OCR/` ומשקפים את מבנה תתי-התיקיות
של התיק, כך שלכל PDF יש מקביל ברור:

```
ניתוח מסמכים/
└── טקסט OCR/
    ├── מסמכי ערר/
    │   ├── כתב ערר + נספחים/
    │   │   ├── כתב ערר - 18.05.25.md
    │   │   └── נספח א' - שומת השבחה.md
    │   └── כתב תשובה - 18.01.26.md
    ├── מסמכים מנהליים/
    └── פרוטוקולים/
```

### כיצד להריץ

השתמש בסקריפט המצורף `scripts/export_ocr_text.py`:

```python
import sys
sys.path.insert(0, "${CLAUDE_PLUGIN_ROOT}/skills/organize-appeal-folder/scripts")
from export_ocr_text import parse_pages, slice_pages, write_markdown

pages = parse_pages(open("ocr_full.txt", encoding="utf-8").read())

# מסמך שלם
write_markdown(pages, "ניתוח מסמכים/טקסט OCR/מסמכי ערר/כתב תשובה - 18.01.26.md",
               "כתב תשובה - 18.01.26")

# נספח שפוצל, בשמירת המיפוי למספרי העמודים במקור
write_markdown(slice_pages(pages, 21, 76),
               "ניתוח מסמכים/טקסט OCR/מסמכי ערר/כתב ערר + נספחים/נספח א' - שומה מכרעת.md",
               "נספח א' - שומה מכרעת",
               source="כתב ערר + נספחים - 18.05.25.pdf", first_src_page=21)
```

כל קובץ נפתח בכותרת, בשורת מקור (שם קובץ המקור וטווח העמודים) ובהסתייגות
שמדובר בפלט OCR ושהמקור המחייב לציטוט הוא ה-PDF. בכל עמוד מופיע סמן
`===== עמוד N =====`, ובמסמך שפוצל גם מספר העמוד במקור, כדי שאפשר יהיה
לאתר במהירות את המקום המדויק ב-PDF.

> **כלל מחייב לציטוט:** קובץ ה-md אינו מקור. לפני ציטוט בהחלטה או במסמך
> מוגש, אמת את הנוסח מול ה-PDF.

## שלב 5: יצירת מסמך סיכום

לאחר הארגון, הפיצול וייצוא הטקסט, צור מסמך DOCX שמסכם את כל התיק.

### בניית מסמך הסיכום

לבניית הקובץ השתמש במנוע `hebrew-docx-engine` (מחבילת `marcus-law-drafting`) - מקור-האמת לעיצוב מסמכי עברית (RTL, פונט David, שוליים, מספור). למבנה משפטי מובנה ראה גם `edit-legal-docx`. אם החבילה `marcus-law-drafting` אינה מותקנת, בנה DOCX עם python-docx לפי הכללים: פונט David גודל 12, RTL מלא (w:rtl לכל run, w:bidi לפסקה ולסקציה), שוליים 2.54 ס"מ, מרווח שורות 1.5.

### מבנה מסמך הסיכום

```
כותרת: סיכום תיק ערר [מספר ערר]
תאריך: [תאריך הפקה]

1. פרטי התיק
   - מספר ערר
   - שם העורר
   - שם המשיבה
   - נושא הערר

2. מסמכי ערר (טבלה)
   | # | שם המסמך | מיקום | תאריך | תיאור קצר |

3. מסמכים מנהליים (טבלה)
   | # | שם המסמך | מיקום | תאריך | תיאור קצר |

4. פרוטוקולים (טבלה)
   | # | שם המסמך | מיקום | תאריך | תיאור קצר |
```

שמור את מסמך הסיכום בתיקיית `ניתוח מסמכים/` בשם:
```
סיכום תיק ערר [מספר].docx
```

## טיפים וכללי אצבע

- **קרא לפני שתסווג**: תמיד קרא לפחות 2-3 עמודים ראשונים לפני שאתה מחליט מה סוג המסמך. שמות קבצים מקוריים לעתים מטעים.
- **תאריכים**: חפש חותמת "התקבל" בפינה העליונה, או תאריך בכותרת המסמך. אם אין תאריך ברור, השתמש בתאריך מטאדאטה של הקובץ.
- **מסמכים כפולים**: אם יש שני עותקים של אותו מסמך (אחד חתום ואחד לא), שמור את שניהם עם תוספת "(חתום)" בשם.
- **קבצים שאינם PDF**: קבצי .msg (אימייל), העבר כמות שהם לתיקיית מסמכים מנהליים. קבצי Word/Excel, קרא את התוכן וסווג בהתאם.
- **תיקיות קיימות**: אל תמחק ואל תשנה תיקיות שכבר קיימות בתיקייה הראשית לפני שהתחלת. הן עשויות להכיל מסמכים שהמשתמש ארגן ידנית.
- **מסמכים שלא ניתן לזהות**: אם לא ברור מה המסמך, שאל את המשתמש לפני שתמיין.
- **גודל תיק**: אם יש יותר מ-30 קבצים, עבוד ב-batches של 10 כדי לא לאבד מיקוד.
- **אל תבלבל בין קריאה להטמעה**: הרצת OCR לקריאה (שלב 1) והטמעת שכבת טקסט (שלב 2) הן שתי פעולות נפרדות. תיק שעבר רק את שלב 1 נראה מאורגן אבל נשאר בלתי ניתן לחיפוש.
- **עבודה בענן מול המחשב של המשתמש**: כשהקבצים יושבים על מחשב המשתמש והעיבוד רץ בענן, בצע את ההטמעה והפיצול בענן והחזר את התוצרים בבת אחת. אם העברת קבצים בודדים מסורבלת, ארוז ל-tar אחד, החזר אותו לתיקיית `_to_delete/` בתיק, ופרוס אותו שם.
- **הרשאות מחיקה**: בסביבות מסוימות אין הרשאת מחיקה בתיקיות של המשתמש. אל תיכשל על כך; העבר קבצים מיותרים ל-`_to_delete/` ודווח למשתמש.

## תלויות

- **PyPDF2**: לפיצול קבצי PDF (`pip install PyPDF2 --break-system-packages`)
- **מנוע hebrew-docx-engine** (חבילת `marcus-law-drafting`): לבניית מסמך הסיכום בעברית; `edit-legal-docx` למבנה משפטי
- **כלי Read**: לקריאת תוכן PDF (עם פרמטר pages)
- **כלי Bash**: להעברת קבצים ויצירת תיקיות
- **OCR למסמכים סרוקים** (`scripts/ocr_with_fallback.py`):
  - `tesseract-ocr` + חבילת השפה העברית `tesseract-ocr-heb`
  - Python: `pytesseract`, `pdf2image`, `requests` (`pip install pytesseract pdf2image requests --break-system-packages`)
  - `poppler-utils` (עבור `pdf2image` ו-`pdftotext`)
  - נפילה ל-Mistral OCR: מפתח מ-Infisical (`/services/mistral`), גישה יוצאת ל-`api.mistral.ai`
- **הטמעת שכבת טקסט** (`scripts/embed_text_layer.py`):
  - `ocrmypdf` (`pip install ocrmypdf --break-system-packages`)
  - `tesseract-ocr-heb`, `poppler-utils`, `pypdf`
  - אין צורך בגישה לרשת בזמן ההרצה
- **ייצוא טקסט טהור** (`scripts/export_ocr_text.py`): ללא תלויות חיצוניות
