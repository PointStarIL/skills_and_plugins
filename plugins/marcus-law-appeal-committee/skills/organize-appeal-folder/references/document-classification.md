# זיהוי סוגי מסמכים ומוסכמת שמות

טבלאות הזיהוי של סוגי המסמכים בתיק ערר, ומוסכמת שמות הקבצים.

## תוכן עניינים

- כיצד לזהות סוג מסמך
- מוסכמת שמות קבצים

### כיצד לזהות סוג מסמך

קרא את 2-3 העמודים הראשונים של כל PDF באמצעות הכלי Read (עם pages parameter). למסמכים סרוקים, השתמש בטקסט שהתקבל מ-OCR (ראה למעלה).
סווג לפי הכללים הבאים:

**מסמכי ערר**, המסמכים המהותיים של התיק:
- כתב ערר (מוגש ע"י העורר/שמאי, מכיל "ערר" או "כתב ערר" בכותרת)
- כתב תשובה (מוגש ע"י הוועדה המקומית, מכיל "תשובה" או "כתב תשובה")
- שומה נגדית / שומת מקרקעין (מסמך שמאי עם הערכות שווי)
- תגובות הדדיות (תגובת העורר / תגובת המשיבה, מסמכים מהותיים שמתייחסים לטענות)

**מסמכים מנהליים**, ניהול ההליך:
- בקשות (להארכת מועד, לפטור, לצירוף מסמכים וכד')
- החלטות ביניים (תגובה לבקשות, אישורים, דחיות)
- הודעות (פתיחת תיק, ייצוג, שינוי מועד)
- הזמנות לדיון
- טיוטות החלטה
- הודעות אימייל (.msg)

**פרוטוקולים**:
- פרוטוקול דיון (תמליל של ישיבה)
- פרוטוקול + החלטה (מסמך חתום שכולל גם את ההחלטה)

### מוסכמת שמות קבצים

שנה את שם כל קובץ לפי הפורמט:

```
[סוג המסמך] - [תאריך בפורמט DD.MM.YY].pdf
```

דוגמאות:
- `כתב ערר - 18.05.25.pdf`
- `החלטה - בקשה להארכת מועד - 09.03.25.pdf`
- `שומה נגדית (אבנר גרון) - 27.05.25.pdf`
- `פרוטוקול דיון - 19.02.26.pdf`
- `בקשה לפטור מהגשת שומה נגדית - 28.04.25.pdf`

כללים:
- התאריך הוא תאריך הגשה/קבלה של המסמך (חפש חותמת "התקבל" או תאריך בכותרת)
- אם יש שם שמאי או גורם רלוונטי, הוסף בסוגריים: `שומה נגדית (אבנר גרון)`
- אם יש החלטה שמתייחסת לבקשה ספציפית, ציין: `החלטה - בקשה לפטור - 30.04.25.pdf`
- קבצי .msg נשארים עם הסיומת המקורית
