# חילוץ נספחים ופיצול PDF

זיהוי הנספחים בתוך כתב הטענות, פיצולם לקבצים נפרדים ואימות התוצאה.

## תוכן עניינים

- סוגי נספחים נפוצים
- תהליך הפיצול
- סקריפט Python לפיצול
- אימות הפיצול

### סוגי נספחים נפוצים

בכתבי ערר ותשובה תמצא לרוב:
- שומות מקרקעין (שומת השבחה, שומה נגדית)
- החלטות ועדות (ועדה מקומית, ועדת ערר)
- מדיניות מהנדס העיר
- תכניות בניין עיר (תב"ע)
- פרוטוקולים של דיונים קודמים
- שוברי תשלום, קבלות, הודעות זיכוי
- תשריטים ומפות

### תהליך הפיצול

1. **התקן PyPDF2** אם לא מותקן:
   ```bash
   pip install PyPDF2 --break-system-packages
   ```

2. **זהה נקודות פיצול**, לכל מסמך, רשום את מבנה העמודים:
   ```
   כתב ערר (17 עמודים):
   - עמ' 1-3: כתב הערר עצמו
   - עמ' 4: שובר תשלום + קבלה
   - עמ' 5: החלטה
   - עמ' 6-17: שומת השבחה
   ```

3. **צור תת-תיקייה** בתוך מסמכי ערר לכל מסמך שיש לו נספחים:
   ```
   מסמכי ערר/
   ├── כתב ערר + נספחים/
   │   ├── כתב ערר - 18.05.25.pdf          (עמ' 1-3)
   │   ├── נספח - שובר תשלום וקבלה.pdf     (עמ' 4)
   │   ├── נספח - החלטה.pdf                (עמ' 5)
   │   └── נספח - שומת השבחה.pdf           (עמ' 6-17)
   ├── כתב תשובה + נספחים/
   │   ├── כתב תשובה - 18.01.26.pdf        (עמ' 1-8)
   │   └── נספח - שומה (אשר בן ישי).pdf    (עמ' 9-13)
   └── שומה נגדית (אבנר גרון) - 27.05.25.pdf  ← מסמך בודד, ללא נספחים
   ```

4. **שם תת-התיקייה**: `[שם המסמך המקורי ללא סיומת] + נספחים`

5. **שמות קבצי הנספחים**: `נספח - [תיאור התוכן].pdf`

6. **שים לב**: מסמכים שאין להם נספחים (כמו שומה נגדית) נשארים כמו שהם בתיקיית מסמכי ערר, אין צורך ליצור להם תת-תיקייה.

### סקריפט Python לפיצול

השתמש בסקריפט המצורף `scripts/split_pdfs.py` או כתוב סקריפט דומה.
המפתח: הגדר מערך של פיצולים ובצע בפקודה אחת:

```python
from PyPDF2 import PdfReader, PdfWriter
import os

def split_pdf(source_path, output_folder, splits):
    """
    splits = [(start_page, end_page, output_filename), ...]
    Pages are 1-indexed, inclusive.
    """
    reader = PdfReader(source_path)
    os.makedirs(output_folder, exist_ok=True)

    for start, end, name in splits:
        writer = PdfWriter()
        for p in range(start - 1, min(end, len(reader.pages))):
            writer.add_page(reader.pages[p])
        with open(os.path.join(output_folder, name), "wb") as f:
            writer.write(f)
```

### אימות הפיצול

סכום עמודי הקבצים המפוצלים חייב להיות זהה למספר העמודים במקור. אם יש פער,
נשמט טווח עמודים; אתר אותו ותקן לפני שממשיכים. דווח את הסכום למשתמש.
