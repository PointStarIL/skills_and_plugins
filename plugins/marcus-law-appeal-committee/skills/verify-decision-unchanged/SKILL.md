# בדיקת שימור, אימות שטיוטה מאורגנת זהה בתוכן למקור

## תוכן עניינים

- תפקיד הסקיל
- מה הסקיל בודק
- פורמט הקלט
- פורמט הפלט
- איך הסקיל מופעל
- מימוש טכני (להנחיית הסקיל המבצע)

## תפקיד הסקיל

לקבל שני קלטים, **הטיוטה המקורית** ו**הטיוטה המסודרת**, ולוודא שאף תוכן משפטי לא שונה.
זוהי בדיקה אוטומטית-למחצה: היא מצביעה על חשד, והמשתמש מאשר/דוחה.

## מה הסקיל בודק

### בדיקה 1, שימור פסקאות (paragraph preservation)

לכל פסקה במקור, לחפש פסקה תואמת בתוצאה. שני אופני התאמה:
- **התאמה מלאה**: אותו טקסט בדיוק (אחרי נורמליזציה של רווחים).
- **התאמה כמעט-מלאה**: שינוי של פחות מ-5 מילים בתחילת/סוף הפסקה (מילת קישור הוספה: "בנוסף,",
  "לעניין זה,", וכו'), מותר.

פסקה במקור שאין לה תואמת בתוצאה → **דיווח: פסקה אבדה.**
פסקה בתוצאה שאין לה תואמת במקור → **דיווח: פסקה חדשה נוצרה. ✗ הפרת כלל ברזל.**

### בדיקה 2, שימור ציטוטים

כל מובאה בתוך גרשיים ("...") במקור חייבת להופיע באותה מילולית בתוצאה. בלי שינוי, בלי תוספת,
בלי קיצור. אם משהו השתנה, **דיווח: ציטוט שונה.**

### בדיקה 3, שימור הפניות לפסיקה ולחקיקה

כל הפניה במקור (עע"מ X/Y, ערר Z, סעיף N לחוק, תכנית A/B) חייבת להופיע בתוצאה בדיוק. הפניה
חסרה → **דיווח: הפניה אבדה.** הפניה חדשה (קיימת בתוצאה אך לא במקור) → **דיווח: הפניה חדשה.
✗ הפרת כלל ברזל.**

### בדיקה 4, שימור התוצאה האופרטיבית

החלק האופרטיבי בסוף ההחלטה ("סוף דבר" / "סיכומו של דבר" / "אשר על כן אנו מחליטים") חייב
להישאר בדיוק כפי שהיה במקור. שינוי כלשהו בתוצאה האופרטיבית → **דיווח: ✗✗ שינוי תוצאה. הפרת
כלל ברזל חמורה.**

### בדיקה 5, שימור משמעות (אזהרת חשד בלבד)

לכל פסקה, להשוות:
- אורך הפסקה (במילים) במקור מול בתוצאה.
- מילים מרכזיות (כל המילים שאינן stop-words).

חריגה מעבר ל±10% → **דיווח: חשד לשינוי משמעות.** זה לא ודאי שמשהו שונה, הסקיל לא מבין סמנטיקה
אנושית, אבל זה דגל שצריך עין אנושית.

### בדיקה 6, מילות קישור שנוספו

לאתר ולרשום כל תוספת של מילה/ביטוי קצר שלא הופיעו במקור. רק אלה מותרות:
- "בנוסף," / "בנוסף לאמור,"
- "לעניין זה,"
- "מנגד,"
- "כפי שצוין לעיל,"
- "ראו לעניין זה,"
- "מן הכלל אל הפרט,"
- "ובענייננו,"
- "סיכומו של דבר,"
- "אכן,"
- "יחד עם זאת,"

- "נקדים ונציין כי,"
- "ודוק,"
- "נחדד כי,"
- "היינו,"
- "ללמדך כי,"
- "הנה כי כן,"
- "דא עקא,"
- "למעלה מן הצורך,"
- "טרם סיום נבקש לציין כי,"

תוספת אחרת → **דיווח: מילת קישור לא מורשית. ✗ הפרה.**

## פורמט הקלט

המשתמש מספק שני קבצים (DOCX או טקסט), או נתיב לקובץ מקורי + טקסט תוצאה מסומן.

## פורמט הפלט

דוח קצר בעברית, מובנה כך:

```
דוח בדיקת שימור
==================

סטטוס: עבר / עבר עם הערות / נכשל

מספר פסקאות במקור: __
מספר פסקאות בתוצאה: __

ממצאים:
1. [כתום] פסקה X במקור: ... → תאמה לפסקה Y בתוצאה? כן/לא/חשד
2. [אדום] ציטוט "..." נמצא במקור אך לא בתוצאה
3. [ירוק] מילת קישור הוספה: "בנוסף," בתחילת פסקה 14, מותר
...

החלק האופרטיבי (סוף דבר): זהה / שונה
הפניות לפסיקה: כולן נשמרו / N הפניות אבדו / N הפניות חדשות

המלצה:
- אם נכשל → לדחות את התוצאה ולחזור לטיוטה המקורית.
- אם עבר עם הערות → לסקור את ההערות הספציפיות.
- אם עבר → ניתן לאמץ.
```

## איך הסקיל מופעל

### אוטומטית
הסקיל `reorder-decision-sections` מפעיל סקיל זה כצעד אחרון שלו לפני החזרת התוצאה למשתמש.
אם הבדיקה נכשלת, הסקיל המארגן לא מחזיר את התוצאה אלא מדווח על הכשל.

### ידנית
המשתמש יכול להריץ את הסקיל בנפרד:
- כשהוא עצמו ארגן מחדש את ההחלטה ורוצה לוודא שלא שינה משהו בטעות.
- כשעבר על תוצאה שהסקיל המארגן הוציא ורוצה אישור נוסף.
- כשמשווה שתי טיוטות שלו לאורך זמן ורוצה לוודא שהשינויים שלו הם רק ארגון.

## מימוש טכני (להנחיית הסקיל המבצע)

```python
# פסאודו-קוד
def preservation_check(original_text, organized_text):
    orig_paragraphs = split_paragraphs(original_text)
    new_paragraphs = split_paragraphs(organized_text)

    findings = []

    # בדיקה 1: שימור פסקאות
    for op in orig_paragraphs:
        match = find_best_match(op, new_paragraphs)
        if not match:
            findings.append(("RED", f"פסקה אבדה: {op[:80]}..."))
        elif similarity(op, match) < 0.95:
            findings.append(("ORANGE", f"חשד לשינוי: {op[:80]}..."))

    for np in new_paragraphs:
        match = find_best_match(np, orig_paragraphs)
        if not match:
            findings.append(("RED", f"פסקה חדשה נוצרה: {np[:80]}..."))

    # בדיקה 2: ציטוטים
    orig_quotes = extract_quotes(original_text)
    new_quotes = extract_quotes(organized_text)
    for q in orig_quotes:
        if q not in new_quotes:
            findings.append(("RED", f"ציטוט אבד: {q[:80]}..."))

    # בדיקה 3: הפניות
    orig_refs = extract_legal_refs(original_text)
    new_refs = extract_legal_refs(organized_text)
    missing = orig_refs - new_refs
    new = new_refs - orig_refs
    for r in missing:
        findings.append(("RED", f"הפניה אבדה: {r}"))
    for r in new:
        findings.append(("RED", f"הפניה חדשה: {r}"))

    # בדיקה 4: תוצאה אופרטיבית
    if extract_operative_section(original_text) != extract_operative_section(organized_text):
        findings.append(("DOUBLE_RED", "שינוי תוצאה אופרטיבית"))

    return findings
```

ה-stop-words לעברית כוללות: של, את, על, אל, מן, מ, ב, ל, ה
