# appeal-decision-writer

מומחה להשלמה וניסוח של פסקאות בחלק "דיון והכרעה" של החלטות ועדת ערר לתכנון ובנייה.

## מטרה

המשתמש כותב טיוטה של החלטת ערר ומסמן בה בסוגריים זוויתיים `<>` מקומות שנדרשת בהם השלמה או ניסוח מחדש. הפלאג-אין מזהה את הסימונים, מתכנן את הכתיבה יחד עם המשתמש, וכותב פסקאות בסגנון משפטי של ועדת ערר, תוך הקפדה על:

- ניסוח בגוף ראשון רבים ("אנו", "לטעמנו", "בענייננו").
- שימוש בפסיקה ובחקיקה רק מתוך הטיוטה והפרויקט. ללא המצאת ציטוטים.
- מבנה 8 הפרמטרים לבחינת שימוש חורג (עצימות, היקף, צד ג', צורך חיוני דחוף, מועד התכנית, גשר תכנוני, הפיכות, שקיפות).
- איסור מוחלט על מקף ארוך (em-dash).

## התקנה

1. ארוז את התיקייה כקובץ ZIP בסיומת `.plugin`:

   ```bash
   cd appeal-decision-writer-plugin
   zip -r appeal-decision-writer.plugin . -x ".*"
   ```

2. בקלוד דסקטופ: לחץ על כפתור "Install Plugin" וגרור את הקובץ `.plugin`.

## טריגרים מומלצים

הפעלת הסקיל מומלצת כאשר המשתמש כותב משפטים כגון:

- "השלם את הפסקאות בטיוטה X"
- "תנסח את פסקאות ההכרעה"
- "תכתוב את חלק ההכרעה"
- "החלטה בערר"
- "צרפתי טיוטה של החלטה"
- "פה אני זקוק לעזרתך בניסוח פסקאות"

## דרישות מערכת
